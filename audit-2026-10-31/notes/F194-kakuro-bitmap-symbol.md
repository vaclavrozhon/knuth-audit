# F194 — wrong bitmap symbol in the kakuro encoding

Volume 4B, first edition, second printing (November 2022), answer
7.2.2.1–430(d), printed page 543 / file page 563.

The sentence about computing intersections calls the second bitmap
`V_vq`. It should be `Y_vq`, the set of allowed digits defined at the
top of the page and used in `x in X_hp intersection Y_vq` immediately
above. `V_vqy` denotes a primary item, and `V_v` a secondary item;
neither is the digit-set bitmap. This is a notation typo, not a failure
of the exact-cover construction.

The original page was inspected. The author's September 2019 draft,
printed page 247, has the same symbol. The current and historical 4B
and Fascicle 5 errata contain no matching correction. Targeted public
searches found no correction; this is not an absolute priority claim.

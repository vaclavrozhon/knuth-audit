# F189 — 46 should be 44 in the futoshiki symmetry count

Volume 4B, first edition, second printing (November2022), §7.2.2.1,
answer392, printed530 / file550. The number of eight-member symmetry
classes should be **44**, consistent with the immediately following
split into26 classes with a long path and18 without one.

This correction also reconciles the paragraph with the displayed totals:

```
173·16 + 26·8 = 2976,
241·16 + 18·8 = 4000,
173 + 26 + 241 + 18 = 458.
```

Thus the 6976 uniquely solvable puzzles occupy414 classes of size16
and44 classes of size8. The printed46 cannot agree with this partition.
No global puzzle census was rerun; this is an internal arithmetic
correction to the reported results.

26+18 split appear in the author's September2019 pre-fascicle, printed234.

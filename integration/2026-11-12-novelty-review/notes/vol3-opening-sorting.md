# Volume 3: opening material, tableaux, insertion and exchange sorting

Reviewed on 2026-11-12 against the second edition, first printing (March 1998), with file-page offset +11. The original typeset pages and the existing detailed arguments were read again. All 19 cards below are retained. This is a review of the specific printed defects, not a claim that the underlying mathematics or corrected algorithms are new.

| Card | Decisive reason and scope |
| --- | --- |
| V3-C0002 | On p. 591 the table determines n/d modulo f/d, not modulo f. With p=17, a=3, f=4, d=2, exponents n=2 and n=6 give the same table key but different claimed answers modulo 4. The May 1981 first-edition replacement on p. 576 already contains the defect; its presence there does not repair it. |
| V3-C0003 | The fixed-matrix inversion generating function on p. 599 omits the inversions between different blocks. The matrix n12=n21=1, with other entries zero, has one inversion, while the printed product equals 1. A factor z^K is needed, where K is the number of these forced inversions. The transpose-symmetry conclusion remains valid. |
| V3-C0004 | The variance formula on p. 605 refers to the alternating-run polynomial G_n, not the ascending-run polynomial g_n. At n=4 their variances are 7/18 and 5/12. The January 2006 correction to a later occurrence of g_n(-1) does not correct this occurrence. |
| V3-C0005 | After Algorithm S stops, its final S5 has advanced r. Thus the vacated cell used on p. 56 is (r-1,s), not (r,s). Even a one-cell tableau demonstrates the mismatch. The deletion algorithm itself is sound. |
| V3-C0006 | In the modified Algorithm S' on p. 70, S4 must return to S2', where K is tested. Retaining S4's jump to S3 can move K outside the shape: the row (2,1) is enough. |
| V3-C0008 | The base case on p. 613 is k=l=0, since the sets start at index zero. For a 3 by 3 square and I=J={1,3}, the actual probability is 1/36, rather than the 1/9 asserted by the printed base case. The 1995 first-edition addition repeats the wrong base case. |
| V3-C0009 | For the permitted key range u=v, the MIX code on p. 616 enters its accumulation loop with index 1 and accesses COUNT[v+1]. A disjoint but adjacent input area can therefore be modified. This is a defect of the MIX implementation; Algorithm D's bounded accumulation loop is correct. |
| V3-C0010 | For Table 4 the no-move counts over its four passes are 5,9,6,9. The stated saving 3(C-T) is therefore 75 units, not approximately 88 on p. 620. The 87-unit claim for Table 3 is unaffected. |
| V3-C0011 | A stack push requires both subfiles to exceed M. For N=4, M=1, no push is possible, but the printed expression on p. 631 gives 1. The exact maximum uses N+1 in place of N+2. The 1984 addition of max(0,...) leaves this defect. |
| V3-C0012 | For uniform pivot density f=1, the integral on p. 633 gives alpha=2; the printed alpha^(-1) n ln n then gives half n ln n, whereas the ordinary quicksort recurrence gives 2 n ln n. One of the two reciprocal conventions must be changed. |
| V3-C0013 | The integral in answer 46 on p. 636 is J_s(n)=sum over j>=1 of (n/2^j)^s exp(-n/2^j). Its difference J_s(2n)-J_s(n)=n^s exp(-n) is nonzero. The printed constant plus periodic term cannot be an exact equality. This local missing remainder is separate from the already published remainder corrections to the main text and answer 48. |
| V3-C0014 | On p. 638 the root z=-1 is not excluded by z!=1 and makes Gamma(z) singular. Even after excluding it, the p=q=1/2 case has an extra entropy divisor in the oscillating term. The general residue also depends on the derivative at each root. This does not assert a new general convergence theorem for the residue sum. |
| V3-C0015 | The median-of-three exchange formula on p. 639 fails for the allowed cutoff M=2. At N=3 the median step orders the three records, with A=1, C=2 and B=0, whereas (C-3A)/5=-1/5. The stated practical optimum M=9 is not contradicted. |
| V3-C0016 | The pair-key rule on p. 585 is inconsistent with its displayed dictionary order: obtaining a before A from the secondary alphabet forces a- before A, while the example has A before a-. The issue is the internal rule/example mismatch, not a dispute over real dictionaries' conventions. |
| V3-C0019 | The January 2006 replacement on p. 64 is too strong. For t=0, the two Gaussian tails beyond n^(1/4+epsilon) are asymptotic to (1/2)n^(1/4-epsilon) exp(-2 n^(2 epsilon)), so the claimed bound lacks an unbounded polynomial factor. The original weaker bound and final formulas (52)-(53) remain valid. This card concerns an error introduced by an erratum. |
| V3-C0020 | The inverse tableau algorithm on p. 614 must ignore the upper neighbor when r=i, both in defining paths and in Q3. The valid 2 by 2 input in the detailed note reaches (i,j)=(2,1), then leaves the remaining region. Novelli, Pak and Stoyanovskii's original algorithm explicitly imposes the corresponding boundary. |
| V3-C0022 | For N=8, T=5 and sum of increments S=16, the printed cost formula on p. 624 is 324+7A, already exceeding the claimed average 276.24. The existing exact argument gives 351.241666...; no exhaustive permutation run was repeated. |
| V3-C0025 | The correct formula on p. 625, 5B+14N+N'-3, gives 433 units for the listed 16-key example (B=41, N'=7), rather than 358 on p. 626. The ordinary Program L time of 496 is unaffected. |
| V3-C0026 | The concatenation code on p. 625 costs 4N+7M-2E+2, where E counts empty lists. Its expected value uses E[E]=M(1-1/M)^N. The combined limiting coefficients on p. 101 should round to 44.62 and 41.89, rather than 44.99 and 41.95. The third coefficient 52.74 remains correct. |

## Errata and prior publication

Compared all five official layers refreshed in this review: [all3-prepre](https://www-cs-faculty.stanford.edu/~knuth/all3-prepre.ps.gz), [all3-pre](https://www-cs-faculty.stanford.edu/~knuth/all3-pre.ps.gz), [all3](https://www-cs-faculty.stanford.edu/~knuth/all3.ps.gz), [err3](https://www-cs-faculty.stanford.edu/~knuth/err3.ps.gz), and [first-edition errata](https://www-cs-faculty.stanford.edu/~knuth/err3-1e.ps.gz). The existing per-topic `workstreams/vol3/sources/*-errata-review.json` files supply the first-edition page mapping. The matching and neighboring entries were read; unrelated typography, references and already corrected formulas are not counted as findings.

Public searches combined Knuth/TAOCP with each page or exercise, and with discrete logarithm, fixed-matrix inversions, run variance, vacated tableau cell, S4, inverse tableau algorithm, hook probabilities, distribution counting, Shellsort saving 88, Pratt 276.24, quicksort stack bound, van Emden, Mellin oscillation, median-of-three exchanges, dictionary order, Gaussian tail, list-insertion 358, and multiple-list times 44.99/41.95. Most exact-number queries returned only the book or irrelevant code-line matches; the broader topic searches were also inspected.

Relevant leads checked:

- [Novelli–Pak–Stoyanovskii (1997), p. 58](https://www.math.ucla.edu/~pak/papers/bij.pdf) contains the correct boundary in Algorithm P'. It supports the repair of C0020 but does not report the later book's transcription defect. Pak's [research page](https://www.math.ucla.edu/~pak/papers/research.htm) points to the book's overview without flagging this defect.
- [Marc Tardif, Sorting Knuth](https://c-scene.com/CS9/CS9-03.html) translates distribution counting with a bounded loop. It does not identify the zero-range MIX defect or the numerical timing errors.
- [Orson Peters, Sorting with Fibonacci Numbers and a Knuth Reward Check](https://orlp.net/blog/fibonacci-sort/) reports the erroneous attribution of a proven bound to a particular Sedgewick increment sequence. That is distinct from C0010, C0022, C0025 and C0026 and is not counted here.
- A [public FFT discussion](https://news.ycombinator.com/item?id=40840396) concerns a sharper but previously valid Volume 2 error bound; it is unrelated. Mellin searches also returned the known binary-Euclidean-analysis correction, not these Volume 3 formulas.

No matching prior public report was found for the 19 specific defects. Search coverage is finite; historical priority and absence from private correspondence are not established. The detailed original notes remain the evidence for the full proofs and instruction counts.

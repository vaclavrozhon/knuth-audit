# The octahedron vector has eight edges instead of twelve

Volume 4A, first edition, first printing (2011), Answer 7.2.1.3–97(a), octahedron size vector,
printed page 743, file page 760.

A simplicial complex is a family closed under taking subsets; its size vector N_t counts its t-element faces. For a triangulated polyhedron, N_1 counts vertices, N_2 edges and N_3 triangular faces. The answer prints `(1,6,8,8,0,0,0)` for the octahedron.

The octahedron has eight triangular faces. Each face has three edges and each edge belongs to two faces, so there are `8*3/2=12` edges. Equivalently its six vertices each have degree four. Replace the third entry by 12. The perturbation described in the exercise does not change these already triangular faces.

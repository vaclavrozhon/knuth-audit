# Dismissed: the matching constraints already use inverse positions

**Location.** Volume 4A, first edition, first printing (2011), note
in answer 7.2.1.2–91, printed page 718 / file page 735.

**Status: dismissed on 11 November 2026.** The original equation (49)
on page 343 uses a'_1, a'_2, ...: these are already inverse positions.
OCR dropped the primes. The initial comparison incorrectly treated
the displayed constraints as inequalities on a_1, a_2, ... themselves.

The permutation 1342 has inverse 1423 and satisfies the actual (49).
Its inversion table 0011 satisfies the note's inequalities. Conversely,
1423 has inverse 1342 and fails the actual (49), consistently with
its table 0002. There is no counterexample and no correction is needed.

The claim that the original (49) had already been visually checked in
the first version of this note was also premature. The subsequent
inspection of images/bookwise-p343.png resolved the error. The finding
card and error location were removed; this note preserves the reason
for dismissal. F0065, the separate asymptotic coefficient issue in
the same answer, is unaffected.

# The ideal exercise omits the variable x_0

Volume 4A, first edition, first printing (2011), Exercise 7.2.1.3–102, opening variable list,
printed page 388, file page 405.

A homogeneous polynomial ideal is closed under linear combinations and multiplication by variables; N_t is the dimension of its degree-t part. The exercise opens with the variables `{x_1,...,x_s}`, but its example for s=2 explicitly uses x_0,x_1,x_2. Its growth bound in part (b), `N_(t+1)>=N_t+kappa_s(N_t)`, also requires these s+1 variables. Here kappa_s is the lower-shadow counting function defined earlier in the section.

Read literally with s=2 and variables x_1,x_2, the ideal generated by x_1 has N_1=1 and N_2=2, with degree-2 basis x_1^2,x_1*x_2. But kappa_2(1)=2, so the claimed inequality would require 2>=3.

Include x_0 in the opening list. The example and the correspondence with t-multicombinations of {0,...,s} in the answer then agree with Theorem M and equation (64).

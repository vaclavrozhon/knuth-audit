# F7-C0011 — The absent-edge label must be a wildcard in166(b)

Confirmed, medium severity, 7 November2026. First digital release, March2025,
ISBN978-0-13-532824-8. Answer166(b), printed195/file210, the last sentence
before the directed-graph parenthesis. Question166 is on130/file145.

The reduction fixes u at a target vertex U and replaces each edge label
incident to u by a new vertex label on the remaining vertices. For a vertex
not adjacent to u, it uses Lambda, extending the old compatibility relation
by making Lambda self-compatible. This is insufficient for ordinary SIP:
a nonedge of the pattern is allowed to map to an edge of the target.

Take the connected pattern u--w--v and the triangle U,V,W as target.
Give every edge one label A; the original compatibility relation is just
{(A,A)}. There are no vertex-label restrictions. Fix u at U. Both choices
for mapping w,v to V,W are valid embeddings.

After deletion, both graphs are single edges, still compatibly labeled A.
The new adjacency labels are1 at w and0 at v in the pattern, and1 at both
target vertices. The prescribed <= comparison allows both assignments.
But the additional label copied from the edges at the deleted vertex is
A at w and Lambda at v, whereas both target labels are A. Extending
{(A,A)} only by (Lambda,Lambda) makes v incompatible with either target.
The reduced instance therefore has no solutions instead of two.

Repair: a pattern-side Lambda must be compatible with every target label,
including Lambda. Existing edge-label compatibility remains unchanged.
The adjacency bit already rejects a real pattern edge mapped to a target
nonedge. The directed version needs the same wildcard behavior in each
direction. This is a local error in the supplied construction, not a claim
that fixing a labeled SIP assignment cannot be reduced.

The analogous self-compatibility in166(a) is adequate, because its extra
adjacency label enforces equality and hence preserves nonedges. Part(b)
explicitly changes that condition to <=; copying the same Lambda convention
does not preserve this distinction. This ordinary connected example avoids
isolates, empty graphs, or incompatible labels at the fixed vertex.

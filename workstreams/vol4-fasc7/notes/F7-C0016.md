# F7-C0016 — The initial support scan lacks an end test without secondary items

Confirmed, medium severity, 12 November 2026. Answer 341, Algorithm A,
step A6, printed 232/file 247. Original first digital release, March 2025,
ISBN 978-0-13-532824-8; the original typesetting was inspected directly.

ITEM is the array of item addresses, with ACTIVE initialized to its number
of entries. Primary items come first; SECOND is the address separating
primary from secondary items. When there are no secondary items, C1 permits
SECOND=infinity, while the concrete initializer in answer 311 uses an
address beyond all real items. Neither initializer supplies a sentinel
entry ITEM[ACTIVE].

Algorithm A establishes the initial support matrix. After checking an item,
A6 increments k and immediately reads ITEM[k]; it continues if the resulting
address is less than SECOND. Thus it can stop at the first secondary item,
but has no end test for an ordinary exact-cover problem with only primary
items. This is a central supported input class, not an empty-input case.

For a small witness, take primary items p,q and the two options {p},{q},
with no secondary items. Both options have the required support and the
unique solution is their pair. With the unextended layout of answer 311,
ITEM=[4,9] and ACTIVE=2. On the first option, A4 skips its own item p,
then finds the other option as support for q. The next A6 sets k=2 and
reads ITEM[2], which was never initialized and is outside the two-item
array. No contradiction or missing support can end this run earlier.
Adding fields to SET changes the addresses, not this failure.

Repair A6 by testing k=ACTIVE immediately after incrementing k and going
to A7 in that case, before fetching ITEM[k]. Otherwise fetch the item and
apply the existing SECOND test. Equivalently, bound the loop by a stored
primary-item count. The latter is what the official companion program
does: establish_dc uses `k<osecond`, and its initializer sets osecond=active
when no secondary items are supplied. No execution of that program is
needed for this direct comparison.

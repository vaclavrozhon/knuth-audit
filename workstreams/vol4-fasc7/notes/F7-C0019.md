# F7-C0019: The projection-table relation need not belong to Inv(O)

**Status:** confirmed, low severity. **Location:** Fascicle 7, first digital release (2025), answer 429, printed page 252 / file page 267, second paragraph.

Here a clone O contains projections and is closed under composition. Inv(O) denotes relations preserved by every operation of O, applied coordinatewise. The answer defines P to contain exactly the truth-table tuples of the k projections, and calls P a relation in Inv(O). That membership claim is false.

Take the Boolean domain D={0,1}, k=2, and let O be the clone generated by Boolean OR, equivalently max. Order the inputs as 00, 01, 10, 11. Then

```
P = {0011, 0101},
0011 OR 0101 = 0111, which is not in P.
```

OR belongs to O, so P is not in Inv(O). This is the same max clone used as an example on printed page 95; no unusual convention or empty case is involved.

The proof's conclusion is correct. Its first paragraph establishes R in Inv(O), where R contains the tables of all k-ary operations of O. The projection tables belong to R because O is a clone. Applying g to those k tuples produces the table of g, which is therefore in R. No invariance of P is required. Delete the words `in Inv(O)` from the definition of P, retaining P as the subset of projection tables.

The original page image `images/bookwise-file267.png` confirms the wording. The official current and cumulative errata downloaded on 12 November 2026 add P subseteq R after the projection list (entry dated 13 September 2026), but do not remove the false membership assertion in the preceding sentence. Thus that amendment does not resolve this issue.

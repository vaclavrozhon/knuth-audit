# F7-C0012 — Answer 224 omits the order-encoding exception

Confirmed, medium severity, 7 November 2026. First digital release, March 2025, ISBN 978-0-13-532824-8. Question 224: printed 135/file 150. Answer: printed 207/file 222. Table 2: printed 40/file 55; definition: printed 41/file 56.

The question asks for clauses fixing u, v, w to colors 0, 1, 2 with Table 2. The answer prescribes (not u1), (not u2), (v1), (not v2), (not w1), (w2), with an additional instruction only for weakened encoding.

For order encoding, Table 2 already requires (not w2 or w1), and page 41 explicitly defines wj=[w>=j]. Thus the last two printed units set w1=0,w2=1 and immediately falsify the domain clause. This makes even a properly 3-colored triangle u--v--w--u unsatisfiable. It does not depend on how graph edges are encoded.

Repair: add the exception “For order encoding, replace (not w1) by (w1).” Then u1u2=00, v1v2=10, w1w2=11, precisely the required colors. The equivalence to log encoding on page 41 involves a change of literals and a color permutation; it does not make the printed units valid with Table 2 as given. The other eight encodings can retain the printed choices.

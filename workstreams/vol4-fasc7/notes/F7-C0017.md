# F7-C0017 — The stated factor 60 disagrees with the benchmark table

Confirmed, low severity, 12 November 2026. Main printed 74/file 89,
the paragraph comparing memory accesses per search node. Original first
digital release, March 2025, ISBN 978-0-13-532824-8. Both that page and
table (130) on printed 73/file 88 were inspected in the original PDF.

The paragraph says that domain consistency uses more than 60 times as
many memory accesses per node as forward consistency on Problems H, O, Y.
For H, however, table (130) gives:

| Method | Memory accesses | Search nodes |
| --- | ---: | ---: |
| Best forward consistency | 19.6 billion | 32.5 million |
| Domain consistency, MRV | 137.4 billion | 4.3 million |

Consequently the ratio of costs per node is

    (137.4 / 4.3) / (19.6 / 32.5) = 52.9841006...,

not greater than 60. Rounding cannot account for the difference: allowing
each displayed number its full nearest-tenth rounding interval gives

    ratio <= (137.45 / 4.25) / (19.55 / 32.55) < 53.847.

This uses the table's fastest domain-consistency method for H, not an
irrelevant experimental variant. The corresponding WTD and FRB columns
have larger ratios, but they do not make the unqualified claim true.
Replacing 60 by 50, or specifying which methods are meant, repairs the
local comparison. The overall observation of substantial extra work per
node remains valid; no historical experiment is disputed or rerun.

Current and cumulative official errata were downloaded and rendered on
12 November. They correct other item lists on page 74 and the K/R entries
of table (130), but neither this factor nor H's four numbers. Searches for
Knuth/137.4/60/errata, the quoted comparison with Problems H, and
err4f7/74/60 found no matching report; this is not an absolute-priority
claim. No external message was sent.

Evidence: `images/bookwise-file088.png`, `images/bookwise-file089.png`,
`sources/file-088.txt`, `sources/file-089.txt`, and the current errata
files and refresh manifest. The two ratios above were evaluated with
exact rational inputs in a single short check.

# F106 — A boundary-ordering example adds a false conflict

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–23(a), p. 420, displayed boundary options

The displayed option can reject a valid queen placement that satisfies the intended ordering.

The example labels its distance-two group a=1 although the stated coordinate definition gives a=2. The bottom-row partner of column 2 should be column 15: r16 c15 a31 b1 y1 y2 y4. Keeping the printed column 14 instead requires removing y1. A complete valid 16-queen placement with boundary tuple (3,9,3,9) demonstrates the false conflict caused by that extra item. Both the local PDF and author PS contain the errors; the rechecked errata have no matching correction. Physical copy not yet checked.

## Publication review, 12 November 2026

DLX 23(a): the first example has the top queen in column 2, so its parameter is a=2. The bottom mate belongs in column 15, with diagonal labels 31 and 1. Keeping column 14 requires removing y1; the stored legal sixteen-queen placement demonstrates the otherwise false exclusion. The published ratio 3.68→3.58 is a separate correction.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

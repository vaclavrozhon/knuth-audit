# F104 — The trie prefix range includes an extra level

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / section 7.2.2, p. 36, trie prefix range

The stated range includes full-word nodes that the described storage layout does not allocate.

On page 36, change the prefix-length range from 0 <= l <= n to 0 <= l < n. Full-length words are represented by terminal ranks, so they do not need 26-entry trie nodes. The six-letter dictionary has 23,667 proper prefixes, as correctly stated in the book; including full words would give 39,394 nodes. A one-word dictionary containing a already demonstrates the difference. Confirmed in both the PDF and original PostScript; no matching erratum was found. The physical copy has not been checked.

## Publication review, 12 November 2026

Page 36: allocated trie nodes represent proper prefixes, with length less than n. The final edges contain word ranks. Including length n would give 39,394 nodes instead of the stated correct 23,667 for the six-letter dictionary. Change the upper inequality only.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

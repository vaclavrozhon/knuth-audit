# V4A-F0032 — The surrogate filter rejects the valid UTF-8 prefix ED 80

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.1.3-199, printed page 619: extra surrogate-exclusion clause

The test falsely rejects the 64 valid scalar values U+D000 through U+D03F.

For the valid bytes ED 80 80 encoding U+D000, the added factor 0x20-((256*a1+a2) xor 0xEDA0) equals zero and rejects the prefix. The constant should be 0x1F.

## Publication review, 12 November 2026

Answer 199, p. 619: the surrogate filter is zero at the valid UTF-8 prefix ED 80, causing rejection. The full sequence ED 80 80 represents U+D000. The subtraction constant must be hexadecimal 1F rather than 20.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0151 — A word-index wrap uses the number of bits

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Section 4.5.4 · Printed page 390

The table occupies lcm(m,30) bits, so an index measured in words must wrap by lcm(m,30)/30

The table occupies lcm(m,30) bits, so an index measured in words must wrap by lcm(m,30)/30. With m=7 there are seven words: decrementing index 0 must wrap to 6, whereas the printed comment gives 209.

## Publication review, 12 November 2026

A circular bit table occupies lcm(m,30)/30 MIX words. The prose restores an underflowed word index by the bit count lcm(m,30). For m=7 this produces index 209 instead of 6 in a seven-word table. The program's M constants already count words; retain as an explanatory-unit defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

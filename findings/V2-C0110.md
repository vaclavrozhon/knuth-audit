# V2-C0110 — The Horner conversion count is off by one

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.4

The surrounding cost comparison understates the number of operations; the program itself is correct.

Program(6) converts m+1 decimal digits. After loading the leading digit it performs exactly m multiply-and-add iterations, whereas the following sentence says m−1. With m=1, converting12 already requires one multiplication and one addition.

## Publication review, 12 November 2026

The input has m+1 digits and program (6) performs m loop iterations, each with one multiplication and addition. The following sentence says m-1. The two-digit case already contradicts that count. The 2018 replacement concerns a later paragraph.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

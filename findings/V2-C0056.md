# V2-C0056 — Wrong parameter in the continuous binomial integral

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.4.1 · Exercise 22 · p. 588

A local parameter typo. Correcting it restores the intended formula; the quantile-correction principle remains valid under its stated approximation premise.

The beta-integral exponent is printed as n−x, although the binomial parameter is t. It should be t−x, consistently with both gamma factors. For t=1, p=1/2 and x=1 the correct CDF value is 1/2; assigning the extraneous n the value 2 would instead give 1/8. The original type and all errata layers were rechecked on 6 November 2026.

## Publication review, 12 November 2026

The continuous-binomial integral uses an undefined exponent parameter `n`; the other factors and the definition use `t`. Replacing `n-x` by `t-x` recovers the stated binomial cumulative distribution at integer arguments.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

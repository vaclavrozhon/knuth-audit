# V3-C0006 — The generalized tableau algorithm skips its stopping test

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / exercise 5.1.4-39, p. 70

Algorithm P can move an entry outside its prescribed shape, even for a two-cell row.

Exercise 5.1.4-39 changes S1 and S2 but inherits S4→S3. Starting with the row (2,1), the horizontal move puts 1 in P11, then skips the K test at P12, clears P12, and finally writes 2 to P22 outside the shape. For S-prime, S4 must return to S2-prime. Original typesetting and all relevant errata checked.

## Publication review, 12 November 2026

In the modified Algorithm S' on p. 70, S4 must return to S2', where K is tested. Retaining S4's jump to S3 can move K outside the shape: the row (2,1) is enough.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

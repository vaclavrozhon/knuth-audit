# V1-C0083 — The 2018 byte-reversal addition admits the wrong zero sign

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §1.3.1, answer 23 · 28 February 2018 erratum for page 509

The added program returns the wrong sign for the zero word under its stated precondition. The original solution is unaffected.

This defect is in the added 2018 answer, not in the original 1997 Dixon program. Rechecked on 5 November 2026.

MIX regards negative zero as numerically nonnegative. Start with rA = -0 and CONTENTS(200) = +0. Each of the five SLA operations preserves the sign, and each zero-valued ADD preserves the old sign of rA. The result is -0, while the exercise explicitly requires a plus sign. This works for every permitted byte radix.

Requiring rA to have a plus sign repairs the seven-instruction program. An initial ENTA 0 removes the precondition but adds one word. Unrestricted space optimality remains open.

## Publication review, 12 November 2026

Numerically nonnegative negative zero survives all five zero shifts and additions with the wrong sign.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0104 — A strict inequality fails when reciprocal error is zero

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.3.3

One proof inequality needs a non-strict sign; AlgorithmR and its final accuracy bound remain valid.

The proof prints0≤vδ_k²<δ_k². With the allowed input v=1/2, R1 gives z_0=2, so δ_0=0 and the strict inequality becomes0<0. Every later iterate also equals2. Replacing the middle sign by≤ preserves the error argument; a general proof of the algorithm is archived.

## Publication review, 12 November 2026

The permitted input v=1/2 makes the initial reciprocal exact and delta_k=0. The intermediate strict inequality is therefore 0<0. Change it to a non-strict inequality. This is a minor proof endpoint; the algorithm and accuracy result remain correct.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

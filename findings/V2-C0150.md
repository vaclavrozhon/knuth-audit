# V2-C0150 — The sieve-pairing index omits a modulus

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Section 4.5.4 · Printed page 389

Using m_k*m_(r-k) pairs m 1 with itself when r=2 and omits m 2

Using m_k*m_(r-k) pairs m 1 with itself when r=2 and omits m 2. For N=31 with moduli 3 and 5, X=7 passes modulo 9 but fails modulo 5. The intended index is r+1-k.

## Publication review, 12 November 2026

The complementary product index must be r+1-k, not r-k. For r=2 the printed expression uses m1 squared and omits m2. The permitted N=31, m1=3, m2=5 example gives a different residue, so this is not a harmless reindexing.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

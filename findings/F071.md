# F071 — Branching depends even on a nonbinding upper bound

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–167, p. 463

Loose upper bounds can change the order and number of visited nodes.

Branching depends on SLACK even for nonbinding upper bounds. An explicit example has five options, 12 solutions, and 37 versus 35 nodes. Checked by a direct root argument, original DLX3, and independent profiles. Confirmed in the PDF and PostScript.

## Publication review, 12 November 2026

DLX 167: changing a nonbinding upper bound can change the SLACK tie breaker of answer 166 and therefore the selected item. The five-option example AX, AY, BU, BV, BW changes the first branch and yields 37 versus 35 nodes with the same twelve solutions. The offset argument would apply only with an invariant item-selection rule.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

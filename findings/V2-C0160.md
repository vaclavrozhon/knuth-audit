# V2-C0160 — The Lucas pretest omits the equality boundary

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume2 · printed 660

Only a proper gcd,1<gcd(N,QD)<N, proves compositeness. The main Lucas criterion is unchanged.

With P=1,Q=-1,N=5, gcd(N,QD)=N and |QD|=N, although N is prime. Q=0 also requires explicit handling.

## Publication review, 12 November 2026

The proposed Lucas precheck exception omits equality: P=1,Q=-1,N=5 gives gcd(QD,N)=N with abs(QD)=N. It also needs to handle QD=0. Use the actual gcd=N exception. This does not refute the main Lucas primality criterion.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V4A-F0061 — Cayley-path proof uses the wrong group count

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.2–72, printed 714: counts for a general permutation group

The endpoint theorem remains true; its counting proof needs the actual group fiber size.

The counts (n-1)! apply only to the full symmetric group. For a general G replace them by the size of the stabilizer of x; the three-element cyclic group is a counterexample to the printed count.

## Publication review, 12 November 2026

Answer 7.2.1.2-72, p. 714: the fiber count (n-1)! is valid for the full symmetric group, not the stated arbitrary permutation group. The cyclic subgroup of order three has one element in each indicated fiber, not two. Replacing the factorial by the stabilizer size repairs the endpoint argument.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V4A-F0007 — Prime probability for n bits is Theta(1/n)

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / answer 7.1.1–52(d), p. 544, prime-probability comment

The incidental probability estimate has the wrong asymptotic order. This finding does not challenge any entry in the game-results table.

A uniformly random n-bit word represents an integer from 0 through 2^n-1, so its prime probability is pi(2^n-1)/2^n. An elementary central-binomial argument proves O(1/n), and a previously proved Chebyshev lower bound gives Omega(1/n). Thus the correct order is Theta(1/n), whereas the answer prints Theta(1/log n). The same paragraph uses n as the bit count in the Fibonacci probability. Original typography and all five relevant 4A/F0 errata layers were checked.

## Publication review, 12 November 2026

Answer 7.1.1-52(d), p. 544: the probability that an n-bit uniformly chosen integer is prime is of order 1/n, not 1/log(n). The nearby Fibonacci-game answer confirms that n denotes the bit count.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V3-C0048 — A t-variable truth table has domain D_t

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Answer 5.3.4-32, printed669: D_(2t) should be D_t

Wrong domain subscript; the Boolean-function correspondence is otherwise unchanged.

A 2^t-entry truth table represents a function on t-bit vectors, as the answer's own indexing formula states.

## Publication review, 12 November 2026

The number of monotone truth tables on t inputs on p. 669 is D_t, not the printed D_(2t). There are 2^t truth-table positions but only t Boolean inputs; these are different parameters. The nearby historical corrections to another function symbol and traversal order do not correct this subscript.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

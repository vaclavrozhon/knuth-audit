# F112 — A Sudoku chart points to the wrong column

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–48(a), p. 425; row 5, value 5

The fixed entry for row 5 and value 5 should be column 4, not column 6.

Answer 48(a) prints 6 at (row 5, value 5), although the original puzzle already fixes the digit 5 in cell (5,4). Every other one of the 162 cells in the two transformed charts agrees with the original candidate grid. The independent coordinate solver and original DLX1 return the same complete solution. The PDF and author PS contain the same typo; current and historical errata do not list a correction. Physical copy not checked.

## Publication review, 12 November 2026

DLX 48(a): row 5, value 5 must name column 4, already fixed in the input sudoku. The printed 6 is a single erroneous entry in the transposed candidate chart.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

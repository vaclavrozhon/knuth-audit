# V1-C0068 — The 2006 correction removes the wrong list endpoint

**Confirmed · critical severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · Published 2006 correction to exercise 27 · book pages 611–612

Applying the published correction can lose free memory and report false overflow.

The published FIFO correction changes the unlinking fields but leaves I4 pointing to the first free block. For head → 0 → 2 → head it allocates 0 and loses the free block at 2.

Load AVAILB[j] into I4 at R2 before the corrected unlinking instructions. This adds 2u. The original 1997 program is correct at this point; the defect is in the published correction. No later physical printing has been inspected.

The original pages and all four current/historical errata layers were reviewed on November 5, 2026. This does not establish priority or inspection of a later physical printing.

## Publication review, 12 November 2026

The 2006 erratum changes last-endpoint unlinking without changing the first-endpoint load.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

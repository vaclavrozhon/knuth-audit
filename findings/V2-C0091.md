# V2-C0091 — Running-time changes for the improved arithmetic routines

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.2.3 · Exercise 4/5

The stated changes in total running time need qualifications, because
changing the precision can also change the path through DNORM.

For answer 5, take normalized operands u = -v != 0. Both routines return
zero without fraction overflow and without any normalization shifts.
The modified routine executes three additional unit-time instructions:
JOV OFLO, DEC2 1, and JNOV DNORM. The other substitutions preserve their
instruction costs. Thus the running time increases by 3u; it does not
decrease by 3u. For equal fractions +1/b and -1/b with exponent QQ, the
complete times are 60u and 63u. The 2012 correction from line 22 to line 23
has been applied.

For answer 4, the increase of 1u, 2u, or 3u is correct before normalization.
It need not be the total increase. With b = 100 and both exponents QQ,
use positive fractions U/b^8 and V/b^8, where
  U = 909090909090910, V = 1099999999999999.
The original product is just below 1/b; the modified product is exactly
1/b. The modification costs 2u before DNORM but saves a 6u normalization
iteration, so total time decreases from 112u to 108u.

Suggested qualification: distinguish the changes before DNORM from the
changes in the normalization path. In answer 5 the extra cost before
DNORM is 3u without fraction overflow and 7u with it; the usual saving of
one normalization iteration is not universal.

## Publication review, 12 November 2026

For opposite normalized operands of equal magnitude, both addition routines take the zero branch without normalization shifts. The modification adds JOV, DEC2 and JNOV, so its time increases by three units, rather than decreasing by three. The stored 60/63-cycle trace agrees with the original instruction paths. For multiplication, the existing 112/108-cycle example saves a six-unit normalization iteration, outweighing two extra earlier units. The 2012 instruction-number correction is included. The numerical outputs and accuracy bounds are not disputed.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

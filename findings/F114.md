# F114 — The stated Sudoku normalization leaves 432 solutions, not 864

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–57, p. 427; first-row normalization and solution count

The reported count retains a stack-swap symmetry that the stated first row already removes.

Answer 57 fixes the first box and row 0 as 1472AB3CD, with A/C = 5/6 and B/D = 8/9. The original DLX1 and an independent bitset enumeration both find exactly 432 solutions. A weaker restriction that lets 2 and 3 exchange the two right stacks reproduces the reported 16,417 options and 864 solutions; every solution pairs with its stack swap. Correct the count or weaken the normalization. Option counts alone can depend on preprocessing and are not a separate finding. PDF and author PS agree; no matching erratum found. Physical copy not checked.

## Publication review, 12 November 2026

DLX 57: after fixing the first box and first row 1472AB3CD as printed, there are 432 solutions. The stored 864 solutions use a weaker normalization permitting exchange of the two right stacks; this freely pairs them, with exactly one partner satisfying the printed first-row condition.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

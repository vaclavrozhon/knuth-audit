# F175 — The auxiliary probability omits one element

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / Mathematical Preliminaries Redux, answer113(a), p.388

Insert+1 in the denominator. The complete-event theorem and all rank-uniformity conclusions remain valid.

The set {k,…,n} union B has n−k+1+t elements, but the printed denominator omits+1. A five-element example makes the displayed inclusion–exclusion sum1/4 instead of1/20.

## Publication review, 12 November 2026

MPR113(a): the union has n-k+1+t elements, not n-k+t. For n=5,k=4 the printed inclusion–exclusion sum is 1/4 instead of 1/20. The missing +1 repairs it.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

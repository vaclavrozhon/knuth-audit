# V2-C0080 — The 2-adic square-root criterion omits zero

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.1 · Exercise 31(d)

The stated equivalence fails at n = 0. Adding this case or restricting n to nonzero integers repairs the criterion.

The square-root criterion needs to exclude n = 0, or list it separately.
As printed, n is any integer and the asserted equivalence fails for zero:
its 2-adic square root is 0, but

0 mod 2^(2k+3) = 0 != 2^(2k)

for every nonnegative integer k.

A minimal correction is to replace "when n is an integer" by
"when n is a nonzero integer". Equivalently, the right-hand condition
can be preceded by "n = 0 or".

The original page was visually checked. All four supplied errata layers
(all2-prepre, all2-pre, all2, err2), and the current err2 TeX, were searched
on November 2, 2026. The corrections to answer 31(c) dated January 26, 2007
and to Hensel's citation dated December 18, 2023 do not address this case.
The latest physical printing and priority have not been checked.

## Publication review, 12 November 2026

Zero is a square in the 2-adic integers but satisfies none of the stated nonzero residue conditions. Add the zero case or restrict n to be nonzero. Retain as a minor endpoint omission, not a failure of the nonzero square criterion.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

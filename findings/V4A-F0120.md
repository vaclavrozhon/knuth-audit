# V4A-F0120 — The expected leftmost-leaf depth has the wrong power of two

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–53(c), printed 795

Replace 2-2^(-n) by 2-2^(1-n). The probability formula later in the same answer is already correct.

For a random degenerate binary tree with n internal nodes, the expected distance to the leftmost external node is 2-2^(1-n), not 2-2^(-n).

## Publication review, 12 November 2026

Answer 7.2.1.6-53(c), p. 795: the mean leftmost depth is 2-2^(1-n), not 2-2^(-n). For n=2 the mean is 3/2, not 7/4. Part (d)'s distribution agrees with this correction; E(2^X)=n+1 is unchanged.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

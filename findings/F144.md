# F144 — The four-way activity example names the wrong item

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–207(c), p. 472

Item 04 has five choices and does not satisfy the stated threshold; item 03 does.

After choosing “00 01” in problem (92), the remaining options are 234, 2345, 245, 34, 35, 45, with the common leading 0 omitted. Items 02, 03, 04, 05 have degrees 3, 4, 5, 4. The four-way branch should therefore be on 03 (or 05), not 04 (or 05). At mu=5/4, item 04 has score 29/9, above the untouched component’s 3, while item 03 has 25/9, below 3. Both source versions agree, and no matching erratum was found. A physical copy and priority remain unchecked.

## Publication review, 12 November 2026

Answer 207(c): after choosing 00 01, item 04 has degree 5, not 4. The four-way branch is on 03 (or 05). The residual options give degrees 3,4,5,4; mu=5/4 and rho=1/2 make the printed branch preference fail for 04.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

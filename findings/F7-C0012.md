# F7-C0012 — Answer 224 makes order encoding inconsistent

**Confirmed · medium severity.** Published fascicle · Digital release 1 · 2025.

Location: Section 7.2.2.3, answer 224, printed 207/file 222: units for order encoding

For order encoding only, replace not w1 by w1. This gives the required representation w1w2=11 for color 2.

The units not w1 and w2 contradict Table 2’s domain clause (not w2 or w1). A colorable triangle with its three colors fixed therefore becomes unsatisfiable.

## Publication review, 12 November 2026

The units for order encoding in answer 224 set w1 = 0 and w2 = 1, falsifying Table 2’s domain clause not w2 or w1. The order-encoding exception must set w1 = 1. The other encodings and the graph-coloring reduction are unaffected.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

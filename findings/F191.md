# F191 — Simple-path recurrence may revisit its start

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / DLX answer405, printed534/file554: missing exclusion of the start vertex

Require w not in S union {v}. In404 this causes overpermissive filtering rather than proving an invalid final solver result.

The transition excludes vertices already in S but omits the fixed start v, permitting the walk v,u,v on a single edge.

## Publication review, 12 November 2026

Answer 405 starts with an empty visited set and fails to exclude the starting vertex on extension. The one-edge graph then admits v,u,v as a simple path. Exclude the union of S and {v}. In answer 404 this only weakens a preliminary filter; it does not invalidate final solutions.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

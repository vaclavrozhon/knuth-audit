# V2-C0240 — Algorithm X needs an exit for a one-symbol alphabet

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Answer 3.2.2–29 · p. 557

A trivial permitted boundary case is undefined; alphabets of size at least two are unaffected.

Exercise17 allows positive m, including m=1. With m=k=1 and x₁=0, X1 sets (a₀,a₁)=(0,0), and X2 has no positive index with aᵢ>0. Returning 0 before X2 handles the case. Our earlier checker already added that branch, so its unary cases checked the supplemented algorithm.

## Publication review, 12 November 2026

Algorithm X on p. 557 lacks the permitted one-symbol case. For m=k=1 its initialization is all zeros and X2 cannot choose an index with a positive entry. Return zero before X2. This is only a degenerate endpoint; ordinary alphabets are unaffected.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

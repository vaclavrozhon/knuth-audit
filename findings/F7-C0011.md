# F7-C0011 — Fixing a SIP vertex needs wildcard compatibility for absent edges

**Confirmed · medium severity.** Published fascicle · Digital release 1 · 2025.

Location: Section7.2.2.3, answer166(b), printed195/file210: compatibility of the new Lambda label

Allow a pattern-side Lambda to match every target label. The separate adjacency bit already rejects missing required edges. The same repair applies to the directed version; part166(a) is unaffected.

In166(b), the path u--w--v has two embeddings into a triangle with u fixed. With every edge labeled A, the new label at v is Lambda while both target labels are A. Merely making Lambda self-compatible rejects both valid embeddings.

## Publication review, 12 November 2026

For ordinary subgraph isomorphism in answer 166(b), the absent-edge label Lambda must be compatible with every target label, not only itself. Fixing an endpoint of a three-vertex path in a triangle gives two valid embeddings, both incorrectly eliminated by the stated compatibility extension.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

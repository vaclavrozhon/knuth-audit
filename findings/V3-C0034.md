# V3-C0034 — Leftist-tree counts mix record nodes with external leaves

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Answer 5.2.3-34, printed 645 / file 656.

The generating-function definitions are inconsistent and the requested asymptotic prefactor is about 0.68837122, instead of 0.25036.

The recurrences imply L=z+O(z²), so G=zL cannot satisfy the stated equation G=z+G(zG). They use a size parameter one larger than the exercise does.

## Publication review, 12 November 2026

The leftist-tree answer on p. 645 mixes counts by internal nodes and by leaves. Its L starts with z, so G=zL starts with z^2 and cannot satisfy G=z+G(zG). The node-count leading constant is about .68837122, obtained by shifting the leaf count; .25036 belongs to the other size convention. The exponential constant remains about 2.7494879. The 1995 replacement already contains the inconsistency.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

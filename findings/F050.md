# F050 — The time test skips valid pivots

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT 376, p. 624

The equality test should be an inequality.

In SIZE(c)−[TIME(l)=T], the comparison should be ≠. The printed expression skips every valid pivot between an old clause and a new one. Checked by a general proof, 1,280 marker combinations, and a reachable 29-clause example of a full round. Confirmed in the PDF and PostScript.

## Publication review, 12 November 2026

Answer 376, p. 624: the timestamp test needs SIZE(c)-[TIME(l)!=T]. All nonpivot literals must be current, giving count SIZE(c)-1+[TIME(l)=T]. For C=(a,b,c) and a new clause (-a,b,c,d), the printed equality rejects the valid pivot. The stored reachable full-round witness supports the local calculation.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0111 — The printer reads beyond the conversion buffers

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.4 · Exercise 13

The second output includes instruction bytes, and asynchronous output can overlap the next buffer update. The computed180 digits are correct.

The program reserves two20-word buffers, but a MIX printer output reads24 words. OUT BUF+20 therefore reaches BUF+43, including four instructions after the allocation. The first output also overlaps four words of the second buffer. Use two disjoint24-word blocks and leave the final four words of each line blank. Its second output therefore includes four code words; asynchronous output also allows the next line to overwrite four words still in use. Volume 1's device definition confirms both facts. The existing forty-eight-word repair and simulation address both faults.

# V4A-F0089 — The Bell-period hint raises g_j to the wrong power

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Exercise 7.2.1.5–24, definition in the hint, printed 434

Define g_j(x)=(x^p-x-1)^(p^(j-1)).

The definition uses exponent p^j; it needs p^(j-1). The printed hint already fails modulo p.

## Publication review, 12 November 2026

Exercise 7.2.1.5-24, p. 434: at p=3,e=1 the hint asserts x^3-x=x^9-x^3 modulo 3 as polynomials. The exponent defining g_j must be p^(j-1), not p^j. This restores the induction's base case without changing the Bell-period result.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F088 — The calculation can return a negative variance

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2–53, p. 406

The second-moment recurrence is missing the cost factor c.

The second-moment calculation is missing c before COST. Two nodes with cost 2 produce variance −4 instead of 0. The correction and general recurrences were checked exactly on 1,000 trees. Confirmed in the PDF and PostScript.

## Publication review, 12 November 2026

Answer 53: the array recurrence omits the node-cost factor before twice COST. A two-node chain with both costs two has deterministic estimate four, but the printed recurrence returns variance −4. The general recurrence immediately above already includes the missing factor.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0061 — The number of changed windows needs a factor k

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.5

The finite window-count bound misses the factor k. The limiting distribution claim remains true.

The count of changed k-tuples needs a factor depending on k. Replacing
U_(j^2) by zero can change up to k overlapping windows per changed term,
so the printed bound sqrt(n) is not valid for k-tuples.

For example, take k=2, n=16, and U_0,...,U_16=3/4, followed by any
completely uniformly distributed tail. Before the replacement, all
16 pairs starting at indices 0,...,15 lie in [1/2,1)^2. Afterwards the
pairs starting at 0,1,3,4,8,9,15 no longer do: seven changes, exceeding
sqrt(16)=4. Even if only pairs wholly inside the first 16 terms were
counted, there would be six changes.

A safe bound for n starting positions is

k * (1 + floor(sqrt(n+k-2))).

After division by n this tends to zero for every fixed k, so the main
conclusion, that complete uniform distribution is preserved, is correct.
Replacing 'at most sqrt(n)' by 'O(k sqrt(n)) for fixed k' suffices.

The original page, all2-prepre, all2-pre, all2, err2, and the current
err2 TeX have been checked; no corresponding correction was found.
The newest physical printing and priority have not been checked.
Nothing has been sent.

## Publication review, 12 November 2026

Changing a term can affect up to `k` overlapping windows. For `k=2,n=16`, the displayed square-position replacement changes seven of the counted pairs, exceeding 4. A bound of order `k sqrt(n)` suffices and preserves complete uniform distribution.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

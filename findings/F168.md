# F168 — The proposed Wald martingale repeats the last summand

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / Mathematical Preliminaries Redux, answer 83, p.382

Use X_k−E X_k inside the sum. The corrected process is a martingale, and the main Wald identity and the direct proof remain valid.

The first line of answer 83 sums X_n−E X_n over k. The resulting n(X_n−E X_n) need not be a martingale; a bounded two-outcome example already fails.

## Publication review, 12 November 2026

Answer MPR83 repeats Xn-E(Xn) inside a sum indexed by k. A fair X1 in {0,1} and all later Xn=0 already violate the asserted martingale property. Both summand indices should be k. The historical correction to the subsequent stopping rule does not fix this line.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F132 — The allegedly unique tiling has a simple second solution

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–120(b), p. 445; exercise p. 138

Answer 120(b) omits an entire valid family: a 3-cell periodic tiling alongside its 13-cell pattern.

Use the second, fourth and sixth tiles shown in family (b). Repeat the three rows 246, 462 and 624 in both directions. Every touching edge matches, including across block boundaries, and no tile is rotated or reflected. The minimal periodic cell has area 3. The book’s 13-cell pattern is also valid; exhaustive neighborhoods and finite propagation certificates prove these are exactly the two translation classes. Requiring every tile type to occur would exclude the smaller pattern, but the exercise does not state that requirement.

## Publication review, 12 November 2026

Answer 120(b): tile types 2, 4, 6 repeated by (row+column) mod 3 form a valid periodic tiling, distinct from the displayed 13-cell pattern. No condition requires using every tile type. The official replacement concerns part (a).

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

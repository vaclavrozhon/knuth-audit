# C017 — “Quickly” rejecting a nonbipartite graph needs qualification

**Candidate · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / section 7.2.2.1, answer 4, p. 416, running-time remark

The stated incidence encoding can make ordinary Algorithm X explore exponentially many nodes before rejecting an unsatisfiable graph.

Place k separate edges before a triangle in the item order. The graph is not bipartite, but MRV with the standard tie break tries both choices for every earlier component before reaching the triangle. Its search tree has exactly 2^(k+2)−1 nodes and no solutions. A general recurrence and two implementations for k=0…9 agree. The PDF and original PostScript both say “quickly”; no matching erratum was found. Because that wording is informal, this remains a candidate clarification rather than a confirmed error. The solution classification itself is correct.

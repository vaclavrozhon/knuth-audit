# C027 — The kernel counts use a restriction that needs a short-period exception

**Candidate · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–91, p. 436

The inferred eight-distinct-word model can omit valid stairs of period two.

The numerical graph counts are reproduced when all eight local words are distinct. But the valid WORDS(136) stair WRITE / WHOLE, with down words WHILE / WROTE, has no such local completion for either kernel. Original DLX2 confirms both exclusions. Requiring eight distinct local words is safe for p≥4; smaller periods need separate treatment. The text does not explicitly impose that restriction, so this is a candidate for clarification of the model, not a claim that the verified periods 5 and 36 are wrong.

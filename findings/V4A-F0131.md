# V4A-F0131 — Forests without unlucky nodes need an alternating reversal

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–117, printed 809

Insert an alternating reversal before the binary conversion; the numerical answer remains 2^(n-1).

The asserted equivalence with degenerate left-child/right-sibling binary trees is false in both directions. Reversing the children of every even-level node before the binary conversion repairs the argument and preserves the count.

## Publication review, 12 November 2026

Answer 7.2.1.6-117, p. 809: the tree whose root has children a,c and whose a has child b has prepostorder r,b,a,c, with no unlucky transition, but a has both binary children. Reversing the two root children gives the converse counterexample. Reverse child lists at even depths before applying the degenerate-binary-tree characterization. The count 2^(n-1) remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

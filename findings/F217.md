# F217 — Activity increase sifts using the old priority

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer262, printed598/file618: Activity increase sifts using the old priority

Set alpha to ACT(k)+DEL, then store and sift with that new value.

The sift-up temporary alpha is captured before the activity increment.

## Publication review, 12 November 2026

SAT262 increases ACT but sifts with the old value alpha. A two-element heap of zero priorities fails its invariant after bumping its child by one. Use the new activity in both storage and comparisons. This affects the heuristic invariant, not logical satisfiability by itself.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

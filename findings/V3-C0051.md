# V3-C0051 — The shuffled-reservoir analysis violates mass balance

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Answer5.4.1-23, printed679: nonuniform recycled input is assigned a uniform-input trajectory

For reservoir size2P the model predicts about3.411429P records per run, versus printed2.857335P; the ordinary FIFO table is unaffected.

Conservation of the P internal records gives a logarithmic initial trajectory. The same continuum model yields run length P(e+ln(P'/P)), instead of the printed parametrized formula.

## Publication review, 12 November 2026

On p. 679, during recycled input, conservation of the P internal records gives P=a(t) integral from x(t) to L of g(u) du, with a(t)=p+qt/T_1. Together with the answer's constant encountered density C, this implies x(t)=(P/C)ln(a(t)/p), contradicting the printed exponential trajectory. The remaining fresh-input interval gives run length P(e+ln(P'/P)) in this continuum model. This is not an assertion of an exact finite-capacity expectation or a proved stochastic limit.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0147 — The sieve needs an empty-range guard

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Section 4.5.4 · Printed page 658

After the known index corrections, N=2 still reads X[1] in an empty table

After the known index corrections, N=2 still reads X[1] in an empty table. An early exit for N<=3 fixes this boundary case; the general sieve argument is valid.

## Publication review, 12 November 2026

With N=2 and M=1, the table is empty after the 2001 corrections, but S1 sets j=1 and S2 accesses X[1]. The original version also outputs 3 outside the requested range. An early return for N<=3 or the appropriate table-size precondition fixes this minor boundary defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

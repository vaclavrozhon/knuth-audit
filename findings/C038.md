# C038 — Candidate: make the positive-size assumptions explicit

**Candidate · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercises and answers 7.2.2.1–184–185, pp. 147, 468

A domain clarification at empty inputs; the positive-size constructions and counts remain correct.

Exercise 184 asks for every count from 0 to Bell(n), but with zero items the only legal instance has one empty cover, so count 0 is impossible. Exercise 185 has no strict instance with zero primary and at least two secondary items: every column would be empty and identical. Positive dimensions may be implicit, so this is an editorial candidate rather than a confirmed failure in the intended domain.

# F081 — The recursive procedure leaves the domain

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2–5, p. 398

For D₁ = {1,3}, it also outputs the inadmissible value 2.

The recursive loop traverses the entire integer interval rather than the domain. For n=1, D1={1,3}, and P1=true, it outputs the inadmissible value 2. Algorithm B is correct. Confirmed in the PDF and the author’s PostScript; no matching erratum was found.

## Publication review, 12 November 2026

Answer 5: iterating over every integer between the minimum and maximum domain value is not equivalent to iterating over the domain. The one-variable domain {1,3} and an always-true predicate make the printed recursive procedure visit the forbidden value 2. The nonrecursive Algorithm B handles the domain correctly.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V1-C0048 — Optimized traversal time omits an instruction cost

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §2.3.1 · Exercise 20 · printed 567

Both optimized time formulas underestimate the actual execution time.

For one node the printed optimized time is 11 u, but the instruction trace takes 12 u. For nonempty trees the corrected totals are 7n+11a−6 for a contiguous stack and 7n+26a−21 for a linked stack. The omitted cost is n−a+1, the number of null left links.

## Publication review, 12 November 2026

A one-node trace takes 12u against the claimed 11u; general counts identify the omitted null-left-link cost.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

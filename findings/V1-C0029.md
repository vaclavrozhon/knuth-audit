# V1-C0029 — Programs A and B can overrun their answer arrays

**Confirmed · critical severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §1.3.3 · Programs A/B · Allocations on printed pages 168 and 174

Valid input fitting the declared limit can produce a longer answer, overwrite memory and corrupt Program A’s code. Program B has the same allocation defect.

MAXWDS=1200 is described as the maximum input length. Both PERM and
ANS reserve MAXWDS words. However, valid nonempty input cycles can
produce a longer disjoint-cycle representation, even after singleton
cycles are removed.

Let a_1,...,a_t,b_1,...,b_t be distinct names. Under the book's
left-to-right composition convention, the product

(a_1 a_2 ... a_t)
  (a_1 b_t a_t b_(t-1) a_(t-1) ... b_2 a_2 b_1)

is (a_1 b_1)(a_2 b_2)...(a_t b_t). Indeed, the second cycle maps
b_i to a_i and a_i to b_(i-1), with cyclic subscripts. Applying the
first cycle and then the second therefore exchanges a_i and b_i.
The input has 3t+4 fields, including parentheses; the answer has 4t.

For t=320, use five-character names A0001,...,A0320,B0001,...,B0320.
The 964 nonblank input fields, blank padding, and final equals field
fit in 61 cards (976 words), well below the 1200-word limit. Every
cycle is nonempty and has distinct elements, as required. The answer
needs 1280 words.

An instruction-level MIX run reaches the first write outside ANS at
line 64, address 2400, after 2938338 instructions. It subsequently
replaces the instruction at OPEN (2458) with the name B0315 and
fails when it returns there, before printing any answer. The 61 input
cards have been echoed. This behavior is additional reproduction;
the field-count construction itself already proves the allocation
insufficient.

One conservative repair is to introduce

MAXANS EQU 2*MAXWDS+23

and change line 03 to

ANS ORIG *+MAXANS

If N is the number of distinct input names, N<=MAXWDS. A surviving
cycle with k>=2 names occupies k+2<=2k words; hence the final answer
has at most 2N words. The extra 23 words cover the terminating zero
and padding written by lines 51-52. Temporary singleton output also
fits this bound with the extra space. The all-fixed case produces
only the two parentheses. The resulting program still fits in MIX's
4000 words and its two-byte index range for every allowed byte radix.

The allocation-only repair produces the exact 1280-word answer for
the counterexample at byte radices 64 and 100, including asynchronous
I/O. Each run executes 3197486 instructions and prints 61 echo rows
plus 54 answer rows. All 37 radices assemble within memory.
This repair does not address the separate question about empty-cycle
input, recorded only as candidate V1-C0028.

No applicable correction was found in all1-prepre, all1-pre, all1,
or err1, searched by page and Program A/input/answer-space wording
on 2026-11-01. Nearby corrections concern input wording, style, or
analysis. No priority claimed. Nothing has been sent.

The same allocation problem also affects Program B, pp.174-175,
line 05 (ANS EQU PERM). It remains after the published correction
ENT3 1 -> ENT3 0. The same t=320 input reaches the first answer
write outside PERM/ANS[2400..3599] at line 60, address 3600, after
945974 instructions. This run stops BEFORE that write; no assertion
about later corrupted execution of B is needed.

Unlike A, B already reserves three 1200-word tables. One conservative
repair that fits MIX memory is to reduce MAXWDS explicitly to 960
(60 cards) and reserve 2*MAXWDS+23 words for PERM/ANS. This changes
B's declared input limit. The last occupied address is 3962. All 37
radices assemble; complete runs at 64/100 on the 60-card t=318 input
produce all 1272 answer words correctly. Preserving the original
75-card limit would require a different storage/output arrangement;
that is not claimed for this simple repair.

## Publication review, 12 November 2026

Valid two-cycle inputs can require more than 1200 answer words in both permutation programs.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F124 — The Monte Carlo trial does not restore its data structures

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.1–86, p. 133; answer p. 434

Later trials run on a damaged problem, so averaging them does not estimate the original search.

Answer 86 empties C6 but keeps C7 and C8. With primary items p,q and singleton options p; q, both return levels uncover q and leave p covered. The first trial has three nodes; the next sees only two. C6 must retain reverse uncommit and i=TOP(x_l), then go to C7 without advancing to another option. Full memory traces prove the failure. The repaired method restores memory on all 10,633 enumerated random paths. Both the local PDF and author PS agree; no matching correction was found in the checked errata. The physical copy remains unchecked.

## Publication review, 12 November 2026

DLX 86: an empty C6 loses both the reverse uncommit operations and restoration of the current item i. The two singleton options p and q already leave p covered after the trial, so a second trial explores a different tree. Preserve rollback and i restoration, skipping only advancement to another option.

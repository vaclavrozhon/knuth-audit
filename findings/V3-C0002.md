# V3-C0002 — The discrete-log lookup determines a residue modulo f/d

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / answer 5-25, p. 591

The table cannot determine the claimed residue modulo f when d is greater than 1.

Replace (n/d) mod f by (n/d) mod (f/d). The relevant group element has order f/d. For p=17, a=3, f=4, d=2, the allowed exponents n=2 and n=6 yield the same lookup key 16 but different claimed residues 1 and 3 modulo 4. The source typesetting and all relevant errata layers were checked. First-edition errata repeat this sentence; they do not correct it. This is a first-pass finding, without a claim of novelty or a physical-copy check.

## Publication review, 12 November 2026

On p. 591 the table determines n/d modulo f/d, not modulo f. With p=17, a=3, f=4, d=2, exponents n=2 and n=6 give the same table key but different claimed answers modulo 4. The May 1981 first-edition replacement on p. 576 already contains the defect; its presence there does not repair it.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0121 — A Lehmer fallback does not imply a large quotient

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.5.2

The explanatory comment is too strong; the algorithm still returns the correct gcd.

With four-digit decimal words and U=10001,V=10000, the two first estimated quotients are1 and0. No simulated step is accepted, so B=0 and full division is used, although the true quotient is only1. The same construction works at other word sizes.

## Publication review, 12 November 2026

In decimal precision four, u=10001,v=10000 produces leading words 1000,1000. The trial quotients disagree immediately, so B=0, although the true quotient is one. The family b^p+1,b^p works at arbitrary word size. Only the explanation that this branch necessarily means a very large quotient is incorrect; Algorithm L remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

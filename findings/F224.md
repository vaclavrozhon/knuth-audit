# F224 — Verifier initialization can accept a false certificate

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer 284, printed 602/file 622: Verifier initialization can accept a false certificate

Initialize VAL(j) to -1, then assign only the dummy variable and the candidate-clause assumptions.

The certificate verifier initializes all variables to true instead of unassigned.

## Publication review, 12 November 2026

SAT284 initializes VAL to 0, meaning true, rather than -1, meaning unassigned. The satisfiable formula consisting of negative a then accepts a false empty-clause certificate. Initialize variables to -1 and assign only the dummy variable and explicit assumptions.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

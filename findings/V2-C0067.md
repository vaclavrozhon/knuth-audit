# V2-C0067 — Dismissed: the count includes the first point

**Dismissed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.5 · Exercise 39

No supported error: the proposed counterexample misreads the printed counting convention.

The original exercise explicitly counts indices j <= n. For N=1 and n=0, choose U_0 < u < 1; then nu_0(u)=1 and the strict inequality holds. The earlier empty-prefix argument silently changed the definition to j < n and is withdrawn.

## Publication review, 12 November 2026

Dismissed. The original counts `j<=n`, while the alleged empty-prefix counterexample counts `j<n`. For `N=1,n=0` and `U_0<u<1`, the original count is 1, so its strict inequality holds. See the dedicated dismissal note.

Decision: `dismissed`. This supersedes the earlier confirmed assessment.

Candidate only: the recorded evidence does not yet establish a book error.

Part (a) explicitly allows integers m,n. If that domain is inherited
by part (b), the displayed special case fails for m=-1,n=1.
The sum from k=0 to -1 is empty and equals zero, while its proposed
value is

(1-(-1))/(2*1) binom(-2,-1) binom(4,2) + binom(2,1)/2 = 1.

This uses the book's convention binom(r,k)=0 for negative integral k.
It does not depend on how sums with more widely reversed bounds
are interpreted. Also, the displayed right side divides by n, so
n=0 cannot be substituted directly.

The formula has been proved for integers n>=1,m>=0, including m>n.
Stating that domain for part (b) resolves these issues. The candidate
status reflects uncertainty over whether this restriction was meant
implicitly for the prefix sum; part (a)'s unrestricted wording makes
it useful to state explicitly.

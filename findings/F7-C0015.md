# F7-C0015 — Residual supports can accept an inactive, uncleared word

**Confirmed · medium severity.** Published fascicle · Digital release 1 · 2025.

Location: Fascicle 7, answer 305, printed 224/file 239: residual-support shortcut combined with Algorithm R in answer 304

The procedure fails to restore domain consistency. Clear and trail removed words, or check that the cached word is still active. The current singleton-domain erratum does not fix this.

Algorithm R removes zero intersections from the active prefix without clearing their stored words. The residual shortcut can then accept a stale nonzero word as a current support. A two-word table with tuples (0,i) for 0<=i<e and (1,e), after deleting y=e, wrongly retains x=1.

## Publication review, 12 November 2026

The residual-support shortcut can read an inactive word that Algorithm R intentionally leaves nonzero. Removing y = e in the recorded (e+1)-tuple example invalidates the sole support for x = 1, but the cached word still passes the shortcut. The defect is missed pruning; it does not by itself establish an invalid final solution.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

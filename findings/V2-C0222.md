The procedure is described as finding all linear factors of a
squarefree polynomial f(x), starting with
    g(x) = gcd(x^(p-1) - 1, f(x)).
This omits the factor x when f(0) = 0. For example, for p = 3
and f(x) = x, g(x) = 1, and all subsequent gcds with g remain 1.

Perhaps say "all nonzero roots" or explicitly remove x first.
Algorithm D itself correctly uses x^p - x and is unaffected.
I have not checked Legendre's original article.

Checked against the available historical and current errata layers.
The latest physical printing has not been checked. Draft, not sent.

## Publication review, 12 November 2026

The historical algorithm as described on p. 449 misses the root zero: gcd(x^(p−1)−1,x)=1. Say nonzero roots or remove factors x first. This review does not assert that Legendre's original algorithm was erroneous; the original historical publication was not independently inspected.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F187 — Reflection filter rejects self-images

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / DLX answer371, printed522/file542: Reflection filter rejects self-images

Apply overlap tests only to distinct images. Literally implemented, the printed rule excludes every proper top-left corner square.

The bidiagonal filter treats a rectangle fixed by a reflection as overlapping a distinct image, rejecting the answer’s own two-cell example.

## Publication review, 12 November 2026

Answer 371(b)'s intersection rejection also rejects rectangles fixed by the tested reflection. For example, (0,1,3,4) at n=4 is a valid two-rectangle orbit but fails b>c. Apply the rejection only to distinct images, or form the set of unique orbit rectangles first.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F223 — Reflected unit propagation omits its value assignment

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer272, printed600/file620: Reflected unit propagation omits its value assignment

Set VAL(|u|) to twice the new current level plus the literal polarity.

The reflection extension appends u and records its location/reason but never updates VAL(|u|).

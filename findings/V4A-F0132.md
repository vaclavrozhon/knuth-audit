# V4A-F0132 — The single-crossing count omits an enclosing block

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.7–27, printed 815–816

The enumeration must include enclosing blocks. For six elements there are 64 with exactly one crossing and 196 with at most one; the book gives 63 and hence 195.

The slot argument omits a block enclosing the crossing pair. The partition 16|24|35 has one crossing; at n=6 the printed formula gives 63 instead of 64 single-crossing partitions.

## Publication review, 12 November 2026

Answer 7.2.1.7-27, pp. 815–816: the slot argument misses blocks enclosing the crossing pair. The partition with blocks {1,6}, {2,4}, {3,5}, at heights 3,1,2, has one crossing. For n=6 there are 64 single-crossing partitions, not the printed 63. The existing six-element verifier was inspected; no general replacement formula is claimed.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0047 — The all-minima modification omits dimension two

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.3.4 · Answer 17 · p. 581

The requested output is missing in dimension 2, and a separate claim about uniqueness fails for one table entry.

Exercise 17 requires every shortest vector for dimensions 2 through T, but the answer only changes S9, which never runs for dimension 2. For a=2,m=5 it should emit ±(2,-1) and ±(1,2). Separately, table row 3 at dimension 6 has two minimum pairs with nonzero endpoints: ±(1,-1,0,0,-1,1) and ±(1,0,-1,-1,0,1). Each has squared norm 4, which is minimal. This contradicts the stated uniqueness exception; the numerical table entry remains correct. Original pages and all errata layers rechecked on 6 November 2026. Later physical printing and priority remain unverified.

## Publication review, 12 November 2026

The exercise explicitly includes dimension two, but the answer changes only S9, which is never reached there. For `m=5,a=2` the two independent minimum pairs are both required. The additional uniqueness statement fails in dimension six for the table's `a=2^18+1,m=2^35`: `(1,-1,0,0,-1,1)` and `(1,0,-1,-1,0,1)` are distinct endpoint-nonzero minimum vectors of squared norm 4. The numerical table remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

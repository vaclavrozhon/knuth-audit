# V1-C0042 — The equality-to-one test in MULT can overflow

**Confirmed · critical severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §2.3.2 · printed 345

A representable three-node expression receives an incorrect derivative.

For MIX radix b, let B=b^5 and c=−(B−1). The input c*x and its correct derivative c are representable. DECA 1 used to test c=1 instead produces −B, leaves negative zero and makes JANZ accept c as 1. The program returns the derivative 1. Both MULT tests should compare with CMPA CON1+1 / JNE while retaining the TYPE check. The symbolic argument and accepted literal runs for radices 64–100 support the finding. The November 5 search of all four errata layers found no repair. Physical printing and priority remain unverified.

## Publication review, 12 November 2026

The unity test alone overflows for a representable constant and changes the resulting derivative.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

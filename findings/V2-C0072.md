# V2-C0072 — The corrected formula still misses the shift 1990

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.6 · Exercise 9(b)

The replacement ran_start on page 187 adds ten calls

The replacement ran_start on page 187 adds ten calls

for (j=0;j<10;j++) ran_array(x,KK+KK-1);

Each call advances the state by 199 positions, so the initialization
advances it by 1990. The formula for h(s) in answer 9(b) needs the
corresponding subtraction of 1990 modulo 2^100-1.

If H(s) denotes the original bit-reversal formula printed in (b),
the correct relation for the updated code is

P_n(z)=z^(H(s)-1990-n) mod (2, z^100+z^37+1),
 h(s)=H(s)-1990 mod (2^100-1).

For seed 0, independent field exponentiation gives the old P_0 as
0xf85b80e5838f40561323f10da, whereas the updated initialization gives
0x756ad685d69f50f0d866a2334 (bits encode polynomial coefficients).
The first generated integer changes from 1028764519 to 58678820,
which even changes its parity.

The common phase shift does not change the separation between streams.
The current standalone rng.c also contains these ten warmup calls;
the generator is consistent, but the exercise answer is not updated.

The original pages and the original errata PDF were visually checked.
No corresponding correction of h(s) was found in all2-prepre,
all2-pre, all2, err2, or the saved current TeX. Later physical
printings and priority are unverified; not sent.

## Publication review, 12 November 2026

The 2002 warmup advances the state by 10 times 199 steps. Thus the answer's old seed phase H becomes H-1990 modulo 2^100-1. The stored bit-polynomial certificate distinguishes the old and warmed first words, 1028764519 and 58678820. Knuth's 2002 news already announces the changed initialization, but does not identify the stale exercise formula.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F123 — A later root option can revive an excluded item

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.1–83, p. 132; answer p. 433

The proposed extension outputs a solution that its new constraint forbids.

Use primary items p,q and secondary items a,b,c, with options p a; p a b; p c; q a. Choose p first. The printed extension returns p c + q a, although the third branch must leave earlier item a unused. The second branch covers a twice and restores it on backtracking. A literal interpreter and the original DLX2 with only the stated extension agree; the expanded problem has no solution. A sufficient repair requires each uncolored terminal marker to occur in only its own root option. This survives the known j>N1 correction and occurs in the PDF and author PostScript. The physical copy has not been checked.

## Publication review, 12 November 2026

DLX 83: pairwise distinct final secondary items do not prevent an earlier such item from occurring inside a later option. For p a / p a b / p c / q a, the modified algorithm covers a twice and later restores the forbidden q a row. Both the literal trace and adapted author program exhibit the invalid solution. A uniqueness hypothesis among the options for p repairs this; the known j>N1 erratum does not.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

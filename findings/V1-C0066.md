# V1-C0066 — Stack allocation rejects an exact fit

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · Exercise 1 · page 607

The allocator can reject a request that exactly fills the available pool.

The pool is explicitly addresses 0 through M−1. Reserving N words at AVAIL is valid when AVAIL+N=M, but the printed test rejects equality.

Use AVAIL+N>M as the failure condition. M=N=1 and AVAIL=0 is a complete counterexample; no sentinel is reserved in this model.

The original pages and all four current/historical errata layers were reviewed on November 5, 2026. This does not establish priority or inspection of a later physical printing.

# C018 — The replacement construction needs a zero-width exception

**Candidate · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / published replacement for answer 7.2.2.1–33, December 20, 2025; p. 422

For the 0×0 input, the 2025 replacement adds an empty option, which the section excludes.

The empty matrix has one solution and no all-zero rows. Appending an all-ones row of length 0 creates an invalid empty option under the definition on p. 71. The original book construction still works and yields two solutions. Requiring n>0 or retaining the original construction for 0×0 resolves this formal boundary case. This concerns the published replacement, not a failure of the original book algorithm. An implicit positive-width convention may exclude the case, so it remains a low-priority candidate clarification.

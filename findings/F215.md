# F215 — Initial unit literals are never written to the trail

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer260, printed597/file617: Initial unit literals are never written to the trail

Write the unit literal to the trail before incrementing F.

The unit-input case updates VAL, TLOC and F but omits L_F←l0.

## Publication review, 12 November 2026

SAT260 initializes a unit's value and position but never writes its literal into the trail. Even input (x1) leaves the slot read by C3 undefined. Add L_F←l0 before incrementing F. SAT13 contains that write.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

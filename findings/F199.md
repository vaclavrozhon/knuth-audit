# F199 — Square encoding excludes odd-length squares

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer 45, printed 556/file 576: Square encoding excludes odd-length squares

For example, z=25 is rejected. Give both factors ceil(t/2) bits and zero the extra product bit.

The answer allocates too few bits to the root when the output width is odd.

## Publication review, 12 November 2026

SAT45 allocates only floor(t/2) effective root bits. For t=5 it excludes 25=5^2. Both factors need ceil(t/2) bits, with the extra product bit forced to zero when t is odd.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

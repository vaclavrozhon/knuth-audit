# V2-C0065 — The gap-creation time is missing +1

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.5 · Exercise 20(c)

A gap can be compared with an earlier partition in which it does not yet exist. Adding one to its creation index repairs the proof.

The definition a_k=max(m-n,m'-n,1) is off by one. A point U_m is first
present in the state with m+1 points, not in the state with m points.
The corrected expression is

a_k = max(m+1-n,m'+1-n,1).

For example, take n=2 and

U_0=0, U_1=1/2, U_2=1/4, U_3=1/8.

The final gap with endpoints U_0,U_3 has length 1/8. The printed
expression gives a_k=1, but the smallest gap after n+a_k=3 points
has length 1/4. Thus the required inequality 1/8 >= 1/4 fails.
The corrected expression gives a_k=2 and compares against 1/8.

With this correction every a_k is in {1,...,n}, and each value
2,...,n occurs at most twice, since an inserted point can bound at
most two final gaps. The remaining harmonic-sum argument works as
printed. This is a local error in the proof; the conclusion of
exercise 20(c) is correct.

The original page, all2-prepre, all2-pre, all2, err2, and current err2
TeX have been checked; no corresponding correction was found.
The newest physical printing and priority have not been checked.
Nothing has been sent.

## Publication review, 12 November 2026

A point indexed `m` is present only when there are `m+1` points. With `n=2` and points `0,1/2,1/4,1/8`, the printed birth index compares a final gap of 1/8 to a minimum of 1/4. Adding 1 inside both relevant index expressions repairs the harmonic-sum proof.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F076 — The optimality condition omits N = 2

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–236, p. 478

“If and only if N ≥ 21” has another valid case.

The condition iff N≥21 omits N=2, when every placement costs 680. The corrected statement, N=2 or N≥21, was proved for all positive integer exponents using complete exact intervals for 21 through 159 and a general bound from 160 onward.

## Publication review, 12 November 2026

DLX 236: the assertion “if and only if N≥21” omits N=2, for which every queen permutation has the same cost 680. Among positive integer exponents the correct condition is N=2 or N≥21. The previous finite and asymptotic optimality certificates were retained, without repeating the enumeration.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

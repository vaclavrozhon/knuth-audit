# F7-C0004 — Answer29 omits the final cyclic index rotation

**Confirmed · medium severity.** Published fascicle · Digital release 1 · 2025.

Location: Fascicle7 / 7.2.2.3, answer29, p163 first paragraph

Rotate the x tuple when assigning the final cells. Without that rotation, literal unranking can assign weight to an invalid matrix. The official implementation already tracks the rotation correctly.

The answer identifies the terminal count-array arguments with the final matrix cells in unshifted order. AlgorithmQ leaves a cyclic buffer whose oldest slot is(n−m+1) mod(n+1). In the2×2 binary problem, c(0,0,1)=2 while the printed cell interpretation admits only one valid completion. The original, all relevant errata and official source were checked; the coordinator independently accepted the contradiction.

## Publication review, 12 November 2026

Answer 29 identifies the final cyclic-buffer arguments with matrix suffix cells without the required rotation. For a 2-by-2 binary histoscape the count interpreted by the printed tuple is 2 versus the actual suffix count 1. The official unranking program performs the rotation and is not faulty.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

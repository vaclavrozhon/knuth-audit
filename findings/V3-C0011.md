# V3-C0011 — The quicksort stack bound is one too large at some boundaries

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / answer 5.2.2-20, p. 631

The formula overstates the required stack capacity by one entry for some input sizes.

Replace N+2 by N+1 in max(0, floor(lg((N+2)/(M+2)))). For M=1 and N=4, both children cannot exceed M, so Q7 never pushes an entry; the printed formula gives 1. In general the minimum input size for depth k is 2^k(M+2)-1. The historical erratum adds max(0,...) but retains the incorrect numerator. Original typesetting and all relevant archived errata layers checked; no matching correction found.

## Publication review, 12 November 2026

A stack push requires both subfiles to exceed M. For N=4, M=1, no push is possible, but the printed expression on p. 631 gives 1. The exact maximum uses N+1 in place of N+2. The 1984 addition of max(0,...) leaves this defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

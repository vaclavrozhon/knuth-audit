# V3-C0004 — The alternating-run variance uses the wrong function name

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / answer 5.1.3-16, p. 605

The variance line names the ascending-run function instead of the alternating-run function.

In answer 5.1.3-16, change var(g_n) to var(G_n). The formula (16n−29)/90 is correct for alternating runs. The previously defined g_n counts ascending runs and has variance (n+1)/12; at n=4 the values are 7/18 and 5/12. The published correction of g_n(-1) on the same page addresses a later occurrence, not this variance line. Original typesetting and relevant errata checked.

## Publication review, 12 November 2026

The variance formula on p. 605 refers to the alternating-run polynomial G_n, not the ascending-run polynomial g_n. At n=4 their variances are 7/18 and 5/12. The January 2006 correction to a later occurrence of g_n(-1) does not correct this occurrence.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

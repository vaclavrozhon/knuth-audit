# V2-C0079 — The zero-free digit set misses some positive real numbers

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.1 · Exercise 24

A supplementary digit-set example fails to represent some positive real numbers, including 3/2. The main classification with a zero digit is unaffected.

The third example after dropping the requirement that 0 belong to D,

D = {2,3,4,5,6,52,53,54,55,56},

does not represent every positive real number. In particular, 3/2 has
no representation with these digits and radix 10.

Let n be the highest occupied position. If n >= 0, the value is at
least 2. If n <= -2, the value is at most 56/90 = 28/45.
If n = -1, a first digit at most 6 gives a value at most

6/10 + 56/90 = 11/9 < 3/2,

whereas a first digit at least 52 gives a value at least 52/10 > 3/2.
These bounds also exclude 3/2 if finite tails of implicit zeroes are
allowed.

Equivalently, the exact set of fractional values is

[2/9,11/9] union [47/9,56/9].

Indeed, subtracting 2 from every digit gives digits a+50c with
0 <= a < 5 and c in {0,1}; their fractional set is [0,1] union [5,6].
Adding 2 to each digit translates it by 2/9.

A minimal correction is to omit this third example. The preceding
example {1,2,3,4,5,51,52,53,54,55} does have the required property.

Source checks: original page 608 inspected. All four supplied errata
layers (all2-prepre, all2-pre, all2, err2), and the current err2 TeX,
were searched on November 2, 2026. The page-608 corrections dated
January 26, 2001 and August 22, 2019 do not change this digit set.
The latest physical printing and priority have not been checked.

## Publication review, 12 November 2026

The digit set {2,3,4,5,6,52,53,54,55,56} cannot represent 3/2. A highest place at least zero gives at least 2; at most -2 gives at most 28/45; at -1 the leading small digits give at most 11/9 and the large digits give at least 5.2. The printed claim of all positive reals is false.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

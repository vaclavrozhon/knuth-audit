# V2-C0063 — The auxiliary depth bound in Theorem W is false

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.5

An intermediate depth bound is false. Theorem W remains true and has a corrected capacity argument.

The auxiliary assertion that U_(s_N) lies in a block B[a_1,...,a_t]
with t <= q+1 is false under the stated choice of q.

Let every subsequence rule select every term, and take r=q=1, N=16.
Then 4^r <= 4^q < N <= 4^(q+1), as required. The block B[1] emits
3 terms, and B[1,1] emits the next 12. Hence U_15 and U_16 are in
B[1,1,1]. In particular U_(s_N)=U_16 has depth 3, not at most 2.
The same issue occurs for N=4^(q+1) for every q>=1.

This is a local problem in the proof, not a counterexample to Theorem W.
For a fixed prefix of length r, reaching depth t requires that its
ancestor blocks at depths r,...,t-1 have already been filled. Their
combined capacity is 4^(t-1)-4^(r-1). Thus t <= q+2 is safe. Using
this weaker bound, and explicitly accounting for the finitely many
ancestor outputs, gives a discrepancy bound

4/sqrt(N) + O_r(1/N),

which still proves the theorem. This does not assert that the final
constant 2 printed in the book is itself false; the issue is the stated
auxiliary justification for the block count.

The original page, all2-prepre, all2-pre, all2, err2, and the current
err2 TeX have been checked; no corresponding correction was found.
The newest physical printing and priority have not been checked.
Nothing has been sent.

## Publication review, 12 November 2026

If every selection rule selects every term, blocks at depths one and two emit only 3+12 terms. At `r=q=1,N=16`, the cited element has depth three, contradicting the intermediate bound of two. The same boundary occurs for arbitrarily large `N=4^(q+1)`. A weaker capacity bound proves the theorem; the report does not claim the final constant 2 is false.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

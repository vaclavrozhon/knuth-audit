# V4A-F0028 — The first black pixel is recorded one column too far left

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.1.3-179, step I10, printed page 613: COL(Q)

The reported first pixel of a black component can be a white pixel immediately to its left.

I10 stores floor(a_j/2), but a black run beginning at column c_j has a_j=2*c_j-1. Its stored first-pixel column is c_j-1 instead of c_j.

## Publication review, 12 November 2026

Answer 179, p. 613, I10: the run boundary is a_j=2*c_j-(j mod 2), so floor(a_j/2) records c_j-1 for a new black run. Page 611 numbers the pixels from one. The first column needs the ceiling already used for the area computation.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

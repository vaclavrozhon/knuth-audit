# V2-C0062 — The direction of prefix predominance is reversed

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §3.5 · Exercise 31

The answer to exercise 31 violates the requested prefix bias. Algorithm W itself meets its own specification; shift its output for this exercise.

The suggested use of Algorithm W gives the opposite prefix inequality.
W6 increments the counter from zero to k=1 before returning V_k, so
U_0=V_1=1/2. Thus the number of the first one terms strictly below 1/2
is zero, whereas exercise 31 requires at least 1/2 for every n>0.

More generally, V_k<1/2 exactly when k is even. Each node of W contributes
a prefix V_1,...,V_j, with floor(j/2) values below 1/2. Summing over
nodes shows that every prefix of the output has at most half its values
below 1/2, independently of the subsequent subsequence rules.

For this construction, use V_(k-1) instead of V_k in W6. Each node then
contributes a prefix V_0,...,V_(j-1), with ceil(j/2) values below 1/2.
Summing gives the required inequality for every prefix. Theorem W still
holds, because Lemma T has the same discrepancy bound for consecutive
indices starting with zero as for those starting with one. Consequently,
using all computable rules still yields a sequence satisfying R5.

The original pages 163, 164, 182 and 597 have been inspected. The
all2-prepre, all2-pre, all2 and err2 lists, and current err2 TeX, were
checked. The December 26, 2002 amendment changes U_n to U_j in the
exercise statement; it does not change W6 or the answer's construction.
The newest physical printing and priority have not been checked.
Nothing has been sent.

## Publication review, 12 November 2026

W6 increments the counter before using it, so its first value is `V_1=1/2`, already contradicting the required lower-half majority. Each node contributes `floor(j/2)` lower-half values. Using `V_(k-1)` gives `ceil(j/2)` instead and preserves the distribution proof. The 2002 correction to the exercise's index is separate.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V4A-F0116 — The change-count variable is not the claimed tail statistic

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–36, sentence introducing h, printed 790

Define h-1 as the number of loop-body executions in T4, counting the final termination attempt, as in the preceding analysis of Algorithm P.

The claimed tail count for the number of changed degree entries fails because an easy transition changes two entries, not one.

## Publication review, 12 November 2026

Answer 7.2.1.6-36, p. 790: h cannot mean the number of changed degree entries. In 3003000 -> 3030000 -> 3300000, both transitions change two entries, while the asserted count for h>1 is one. The intended statistic is one plus the number of T4 loop executions, including the final termination attempt, consistent with the analysis on p. 450. The leading 4/23 proportion remains correct.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

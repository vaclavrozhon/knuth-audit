# V2-C0013 — An inversive-generator proof uses the wrong index

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Answer 3.2.2–36 · p. 558

An intermediate identity is false; the main period theorem survives the correction.

In the difference-of-squares factorization, the last qₙ₊₁ should be qₙ₋₁. For a=1,c=2,n=1, the printed sides are 4 and 8. The same index should be adjusted in the following sentence to use the intended factor. The corrected proof establishes the period theorem.

## Publication review, 12 November 2026

The factorization fails numerically at n=1; the second q_(n+1) must be q_(n-1).

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

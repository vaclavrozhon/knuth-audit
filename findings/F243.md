# F243 — Negative-infinity boundaries make every sweep value negative infinity

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT459, answer639/file659

Use0 at empty boundaries in the binary setting, as the earlier author draft already does.

The recurrence never obtains a finite starting value.

## Publication review, 12 November 2026

SAT459's recurrence starts all empty boundaries at negative infinity and consequently never produces a finite value. Use zero for the nonnegative binary-matrix problem. The 2015 author draft already used zero; the later printing introduced the defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V3-C0063 — The 2–3 tree estimate uses the wrong size parameter

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Exercise 6.2.3-27, printed 480, and answer 718: N internal nodes versus N keys

Change the exercise parameter to the number of keys to match the answer.

A four-node, six-key 2–3 tree can need four comparisons, exceeding 2 lg(4+2)-2; the expression agrees when N counts keys.

## Publication review, 12 November 2026

Exercise 27 on p. 480 defines N as internal nodes, but the formula on p. 718 uses the key count. A root [2,5] with children [1], [3,4], [6] has four internal nodes and six keys; searching for 3.5 needs four comparisons. The displayed 2 lg(N+2)-2 is below four with N=4 and equals four with N=6. The answer's drawn family has the same size mismatch.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

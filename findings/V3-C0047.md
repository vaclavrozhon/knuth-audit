# V3-C0047 — Uniform sorting does not compare the same pairs as Algorithm Q

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Exercise 5.3.4-64, printed246 and answer675: false comparison-pair equivalence to Algorithm Q

The claimed equivalence and induction fail for this partition implementation. Exercise65's average is not refuted.

Input (4,2,1,3) with M=1 makes Algorithm Q compare all six key pairs; uniform sorting skips (1,3) by the known chain 1<2<3 and makes five comparisons.

## Publication review, 12 November 2026

The assertion on pp. 246 and 675 equating uniform sorting with Algorithm Q does not hold for Algorithm Q as printed, which reorders the records. On (4,2,1,3), cutoff M=1, Q makes six nonredundant pair comparisons; uniform sorting in original-index order makes five, using transitivity to skip the pair (1,3). Both sort correctly. A different pivot convention could support a related statement but is not the printed algorithm.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

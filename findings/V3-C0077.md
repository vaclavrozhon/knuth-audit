# V3-C0077 — The double-hash comparison halves the probe cost

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Answer 6.4-18, printed 731, versus Program D on 530–531

Use the 8C contribution and account separately for wraparound; the stated thresholds need revision.

The answer credits 4u per saved probe, but the unchanged Program D loop costs 8u per extra probe.

## Publication review, 12 November 2026

The common probe loop in Program D costs 8 units per additional ordinary unsuccessful probe. Answer 6.4-18 credits only 4 times the change in the probe count although (30) and (31) replace only the step-size calculation. The total 8C term is explicit on p. 531 and in the 1980 first-edition correction. The old 94%/71% thresholds are not justified; no universal replacement thresholds are asserted.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

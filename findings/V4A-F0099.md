# V4A-F0099 — The exponential in the integrand uses x instead of z

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.5–48, first displayed sum, printed 773

Change exp(kx) to exp(kz) in the first line.

The first summed integrand contains exp(kx), although the expansion requires exp(kz).

## Publication review, 12 November 2026

Answer 7.2.1.5-48, p. 773: expanding exp(exp(z)) requires exp(k*z), not exp(k*x). At x=1 the erroneous closed-contour integral is zero, while the correct coefficient is e. The next line already uses the correct variable.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

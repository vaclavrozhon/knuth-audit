# V4A-F0020 — The replacement bytewise min/max routine expands its mask incorrectly

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / official errata for answer 7.1.3-98, p. 598

The official replacement fails to exchange all bits of selected bytes and returns incorrect minima and maxima. The original first-printing routine does not contain this defect.

The replacement expands a comparison flag with (t-(t>>1))+t, turning #80 into #c0 instead of #ff. For x=0,y=1 it returns maximum 0 and minimum 1. The shift must be by 7 bits.

## Publication review, 12 November 2026

The June 30, 2016 replacement for answer 98, p. 598, expands flag 128 to 192 rather than 255 because it shifts by one instead of seven. With x=0,y=1 it consequently returns the wrong bytewise minimum and maximum. This is a defect in the replacement, not the original first-printing routine.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V1-C0061 — SCOPE construction reads an empty stack at end of input

**Confirmed · critical severity.** 3rd edition · 1st printing · 1997.

Location: Volume1 · §2.4, answer13 · printed page606

The printed end-of-input path fails after every nonempty valid input before reaching its termination test.

The answer sets L=0 at end of input and waits until A7 to stop. After the valid one-item input “1 A”, A5 first removes the real node, then removes the sentinel (0,NULL), attempts SCOPE(NULL), and reads the top of the now empty stack. This remains invalid even if the correct next address is supplied and the unwanted symbol-table update is skipped.

The same failure occurs after every finite nonempty valid input. At EOF, directly pop only positive-level entries, assign their SCOPE to the last real address, and stop in A2 without allocating a dummy item. The original pages and all four current errata layers were checked again on November5,2026; no correction of answer13 was found. Later physical printings and priority remain unverified.

## Publication review, 12 November 2026

End of input removes and dereferences the null sentinel before the termination test.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

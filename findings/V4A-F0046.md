# V4A-F0046 — The ZDD support algorithm compares masks with node indices

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer7.1.4-197, printed659: zero-child tests in the support algorithm

The master-chart weights and the computed variable-order objective can be wrong even for an ordinary one-variable function. Both zero-child tests require node indices.

The algorithm compares support bit masks with the index of the zero node. Both terminal masks are zero, so even the root for f(x1)=x1 is assigned empty support and misidentified as zero. Compare child indices h and l with zeta instead.

## Publication review, 12 November 2026

Answer 197, p. 659: support masks are compared with the index of the zero-function node. Both terminal support masks are zero, so the one-variable function x1 incorrectly receives empty support and is classified as zero. Compare child indices with zeta instead.

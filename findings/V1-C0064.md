# V1-C0064 — The compaction time formula has 25c instead of 24c

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · Exercise 34 · page 615

Adding the printed instruction frequencies with MIX execution costs gives 44a + 17b + 2w + 24c + 8d + 47. The book prints 25c. Here c counts runs of inaccessible nodes.

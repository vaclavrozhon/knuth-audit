# V3-C0071 — The subgroup-membership procedure can cycle

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Exercise 6.3-41, printed 511–512: claimed termination of subgroup membership

Length-preserving reductions require an additional termination rule.

The valid single generator ab and query a produce a -> b^(-1) -> a indefinitely, with no rejection condition triggered.

## Publication review, 12 November 2026

The one-generator system theta=ab satisfies the stated Nielsen condition. Query a reduces to b^−1 and then back to a, each time with k=l=1. The rejection test l>k never fires, so the asserted termination fails. No general repair of the algorithm is claimed.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F061 — The first interval should be [0..0]

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–442, p. 546

The only cell of a 1 × 1 grid must be white.

The first interval for the number of black cells should be [0..0], not [1..1]: the single cell of a 1×1 grid is white. The remaining intervals and all 45 counts agree. Confirmed in the PDF and PostScript.

DLX 442: the first multiplicity interval in the hitori encoding must be [0..0], not [1..1]. A single white cell exposes the mismatch directly.

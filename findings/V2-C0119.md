# V2-C0119 — Signed subtraction can make the ternary gcd loop forever

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.5.2 · Exercise 5

The literal exercise algorithm can fail to terminate on valid positive inputs.

At(1,7), using u−v and removing factors of3 produces−2. Replacing max(u,v) leads to(1,−2), which the subsequent iteration leaves unchanged. Use |u−v|. This preserves positive operands, decreases their maximum and agrees with the worked table. The main binary gcd algorithm is unaffected.

## Publication review, 12 November 2026

In the ternary variant, u=1,v=7 yields t=-6 and then -2; the subsequent replacement rule cycles. Taking the absolute value before removing powers of three repairs it. The book's own worked example already uses the positive difference.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

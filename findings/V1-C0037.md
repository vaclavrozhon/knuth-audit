# V1-C0037 — Polynomial aliasing needs a missing minus-one exception

**Confirmed · high severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §2.2.4 · Answer 9 · printed page 552

The claimed result for shared P and Q can fail and leave the structure invalid.

Take P=Q=1, a separate M=-1, and an empty free list. The multiplication cancels the only term. StepA4 frees that node before advancing P, so P reads the overwritten free-list link instead of the polynomial head. The 2022 correction changes the Q update but does not repair this aliasing case. The answer must exclude a constant term of -1 in M, except for the harmless zero P case. The analogous exception for M=Q is already printed. The failure is a direct invalid-pointer trace, supported by accepted MIX checks; no timeout or memory allocation is needed to demonstrate it.

## Publication review, 12 November 2026

Cancellation frees the node still used by the aliased source pointer in the supposedly supported P=Q case.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

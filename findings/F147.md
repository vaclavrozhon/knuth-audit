# F147 — The 128-queen diagram is missing its last queen

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–236, p. 477, 128-queen diagram

The displayed solution contains 127 queens and leaves its last row empty.

The bottom-right diagram on page 477 omits the queen at row 128, column 65, counting from the top left. Both the book and author draft contain exactly the same other 127 queens. Adding the missing queen gives a valid placement and exactly matches the full permutation in Fischetti and Salvagnin’s original paper. Both enlarged source images were inspected. No matching correction was found in six archived errata layers.

## Publication review, 12 November 2026

Answer 236: the displayed 128-queens board has only 127 queens and an empty final row. The missing queen is at (128,65), matching the last entry of Fischetti and Salvagnin's original list. The fresh bottom crop confirms the empty row.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

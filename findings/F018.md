# F018 — The example contains an extra item

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / p. 468, answer 180

The listed object violates the condition of exactly four occurrences.

There is an extra i_2 in o_6, contradicting the exactly four occurrences specified two lines earlier. A strict example uses t=u=4. Confirmed in the PDF and PostScript; this is separate from the known correction to the exercise on p.147. No matching correction was found in the complete 4B and Fascicle 5 errata; the physical copy has not been checked.

## Publication review, 12 November 2026

Answer 180, p. 468, first confines i_2 to o_2,o_3,o_4,o_5, then incorrectly adds it to o_6. Delete that occurrence. The strict staircase rows 1000,1100,1110,1111,0111,0011,0001 satisfy the intended conditions. The known 2026 correction to the exercise does not repair this answer.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

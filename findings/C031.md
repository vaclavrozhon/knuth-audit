# C031 — Color symmetry may require a fixed order within each option

**Candidate · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–122, p. 446; exercise p. 138

The threshold modification can keep both symmetric solutions or discard both if corresponding options use different item orders.

With primary p and secondary x,y, the options p x:1 y:2 and p y:1 x:2 are symmetric as mathematical sets. Both use both colors, but both encounter color 1 first and are accepted. Writing the same options as p y:2 x:1 and p x:2 y:1 makes the modification reject both. Sorting items in a fixed order restores one representative. Independent implementations and all 36 order pairs confirm this behavior. This remains a candidate: total symmetry may implicitly include the ordered representation, in which case the example falls outside the intended assumption.

# F102 — The reported memory cost is ten times too large

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2–27, p. 401

The comparison overstates the cost of searching 6×5 word rectangles.

Answer 27 reports about 18.3 teramems; the unchanged author program uses 1,828,460,227,444 memory accesses, or about 1.83 teramems. All 625,415 solutions, the full search profile, and the average domain sizes were checked. An independent bound from the printed profile and the algorithm is below 6.636 teramems, ruling out 18.3. Confirmed in the PDF and original PostScript; no matching erratum was found. The physical copy has not been checked.

## Publication review, 12 November 2026

Answer 27: the completed unmodified author program used 1,828,460,227,444 memory accesses, approximately 1.83 teramems, not 18.3. Independently, the printed profile and rounded mean domain sizes imply a conservative upper bound of 6,635,380,138,340 accesses, already refuting 18.3. The precise revised value relies on the stored completed run, not a new timing experiment.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

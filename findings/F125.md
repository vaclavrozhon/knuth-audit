# F125 — The cleansing estimate is missing the branching factor

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.1–86, p. 133; answer p. 434

The claimed unbiased estimate can always return half the actual number of cleansings.

The cost of the sampled option needs weight D×theta, so DC must be D×theta×C. With primary p, secondary x, and options p x:A; p x:B, exhaustive search performs two cleansings. Each trial has D=1, theta=2, C=1 and the printed estimate is always 1. A direct proof, independent set model, and original DLX2 agree. The repaired cost profiles match exact expectations at every depth over 10,633 paths. This fault persists after repairing C6. PDF and author PS agree; the checked errata contain no matching correction. A physical copy remains unchecked.

## Publication review, 12 November 2026

Answer 86: a cleansing count C after choosing one of theta branches has sampling weight D*theta, not D. Two differently colored options on p and x already give estimate 1 instead of the full count 2. This is independent of the rollback defect in F124.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

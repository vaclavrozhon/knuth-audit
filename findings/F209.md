# F209 — Virtual unit reductions are undone without being counted

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer175, printed581/file601: Virtual unit reductions are undone without being counted

Assign CSIZE←s before the test; a three-literal clause otherwise returns from lookahead with stored size four.

Answer175 writes the decremented CSIZE only for s≥2, while undo increments for every processed false literal.

## Publication review, 12 November 2026

SAT175 decrements the stored size only when the residual clause has at least two literals, but undo increments it unconditionally. The fixed three-literal example returns with size four. Store every decrement before the branch; the archived SAT11K code already does this.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F085 — The algorithm selects from the old class

**Confirmed · critical severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2–44(b), p. 404

It can return an already selected green word instead of the new candidate.

The selection reads the class of the old x rather than the chosen c. With m=2 and prefix 0001,0011, it returns green 0011 instead of blue 0111. The correction was checked exhaustively for m=2 and m=3. Confirmed in the PDF and PostScript; no correction was found in the public errata.

## Publication review, 12 November 2026

Answer 44(b): candidate selection must use the class c selected in part (a), not the class of the old x. After 0001 and 0011, the old expression returns the already selected 0011 instead of the sole blue candidate 0111. The author program already selects the intended class; that correct implementation is not itself an explicit error report.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

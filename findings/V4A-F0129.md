# V4A-F0129 — Absolute values must be inside the off-diagonal sum

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–104(a), parenthetical on printed 806

The general matrix assertion is false; the surrounding argument for graph Laplacians is unaffected.

The claimed sufficient condition for a real symmetric matrix to have nonnegative eigenvalues uses the absolute value of an off-diagonal row sum. It must use the sum of absolute values.

## Publication review, 12 November 2026

Answer 7.2.1.6-104(a), p. 806: absolute values belong inside the off-diagonal sum. The symmetric matrix with rows (1,2,-2), (2,1,-2), (-2,-2,4) meets the printed weaker condition but has eigenvector (1,-1,0) with eigenvalue -1. The surrounding graph-Laplacian argument remains valid because its off-diagonal entries share a sign.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V3-C0036 — The radix timing analysis counts an untested empty pile

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Program R timing, printed174–175 and answer6 on651: empty-pile distribution wrongly includes pile0

Changes the minimum and expected E, and hence the expected running time. The sorting program is correct.

The program excludes pile0 from its empty-pile tests, but the stated occupancy distribution includes it.

## Publication review, 12 November 2026

The radix-sort program on pp. 174-175 tests bins 1 through M-1 for emptiness, excluding bin 0. Its answer on p. 651 uses the distribution for all M bins instead. With N=2, M=3 and digit columns 111 and 222, the actual tested-empty count is zero although the proposed distribution requires at least three. The time expression is consistent when its empty-bin variable excludes bin 0.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

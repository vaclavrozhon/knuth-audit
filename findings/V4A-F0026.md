# V4A-F0026 — A new component has an uninitialized child pointer

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.1.3-179, step I10, printed page 613: initializing a new component

The printed pointer algorithm can follow an undefined child address on an ordinary nonempty image.

I10 initializes the new node's parent, sibling and other fields but omits CHILD(Q). The next row's double-order traversal reads that unset field.

## Publication review, 12 November 2026

Answer 179, p. 613, I10: the new component's CHILD field is never initialized, though the subsequent traversal reads it. Two identical rows 010 reach that read. I1 initializes only the root; no blanket zero-fill premise is given.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V4A-F0047 — The exact-cover profile comparison subtracts an absent node

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer7.1.4-211, printed663: exact-cover profile inequality

The intermediate inequality is false. Replacing q[k]-1 by the nonzero-cofactor count q′[k] preserves the intended Z(f) <= B(f) conclusion.

The exact-cover profile comparison subtracts a zero cofactor even when no zero cofactor exists. Six distinct nonzero rows give q[1]=z[1]=2, contradicting q[1]-1 >= z[1].

## Publication review, 12 November 2026

Answer 211, p. 663: the exact-cover comparison subtracts a zero residual even when none exists. For rows ab,cd,a,b,c,d, the two residuals after the first choice are nonempty, distinct, and both support the next row; q1=z1=2. Replace q_k-1 by the number of nonzero residuals. The final Z<=B result remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

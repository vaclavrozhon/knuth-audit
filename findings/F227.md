# F227 — Purge tie breaking discards the number that should be kept

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer 288, printed 603–604/files 623–624: Purge tie breaking discards the number that should be kept

Discard sj+mj-T least-active boundary clauses, including the case T=sj.

The procedure discards T-sj clauses at the boundary range, although T-sj is the number it should retain.

## Publication review, 12 November 2026

Independently, SAT288 discards T-sj boundary clauses although that is the number to keep. The discarded number is sj+mj-T, including the equality case T=sj. The example sj=2,mj=6,T=4 exposes the reversed count.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

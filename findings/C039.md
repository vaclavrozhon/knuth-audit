# C039 — The source of the stated 2010 population needs clarification

**Candidate · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / main text 7.2.2.1, p. 115, official 2010 population

Open attribution question; frozen benchmark data are preserved.

The printed total 306,084,180 exactly matches Knuth’s SGB file. The original 2010 census gives 306,073,283 for the 48 states. The official 2015 estimates baseline matches every SGB value except California, which differs by −1,608; its 48-state sum is 306,085,788. The origin of that California value is unresolved. Knuth describes SGB data as frozen examples, so this is a candidate about the book’s factual attribution, not a confirmed algorithm error.

# F204 — Adjacent-pair clauses mix sequence length and leaf count

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer117(b,c), printed572/file592: Adjacent-pair tree indexing

Increase those input subscripts by one and use 2k=n−2 in the three-leaf case; 011111 otherwise incorrectly satisfies an at-most-three bound.

The two-leaf formulas retain indices for n leaves even though the tree has n−1 adjacent-pair leaves.

## Publication review, 12 November 2026

SAT117 uses n input bits but n-1 pair leaves. The new two-leaf clauses need input subscripts increased by one, and the three-leaf identity is 2k=n-2. At n=6,r=3 the printed encoding accepts 011111 despite its four adjacent 11 pairs. The author's helper instead consistently uses a pair-count parameter.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

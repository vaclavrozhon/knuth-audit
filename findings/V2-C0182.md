# V2-C0182 — The BBS vote definition is missing a plus sign

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.5.4 · printed 669

A valid local example reverses the vote bit. The saved corrected construction handles the complete reduction.

The displayed vote uses floor(alpha_t*j*beta_t+beta_(t+1)). It needs floor(alpha_t+j*beta_t+beta_(t+1)); the next formula already has the correct sum.

## Publication review, 12 November 2026

G_j contains a product alpha_t*j*beta_t where alpha_t+j*beta_t is needed. The following floor identity already has the plus sign. The permitted exact m=209 example changes the floor from -1 to 0 and can reverse a vote. This is visible in the typesetting, not an OCR artifact.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# F113 — Two indices are inconsistent in the Sudoku matching answer

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–49(a,b), p. 425; matching indices

Use the row index for column-graph vertices and r for the number of remaining vertices.

In answer 49(a), an option p_(i,j0)c_(j0,k) must give edge u_i–v_k; the printed u_j uses the wrong index. The candidate (2,0,2), for example, belongs to u2. In 49(b), the complement has r−q vertices, as defined in the question, rather than the printed n−q. These are grouped as one notation finding. Writing x0 consistently in the box formula is also clearer; its implicit x=x0 convention is not counted as a separate error. All graph constructions and eliminations are independently verified. PDF and author PS agree; checked errata contain no correction. Physical copy not checked.

## Publication review, 12 November 2026

DLX 49(a,b): in the column construction the varying row index is i, hence the left endpoint is u_i. In part (b), the complementary size is r−q, using the variable introduced in the question, not n−q. The Hall-style matching argument otherwise remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

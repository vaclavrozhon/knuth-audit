# V2-C0007 — The return-gap bound needs a separate k=2 case

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Answer 3.2.2–15 · p. 554

The ancillary period bound is false for a two-cell table.

With m=16, a=5, c=1 and a two-cell shuffle table, the gap sequence has least period 8, exceeding the claimed bound 4. Its maximum gap is 5<8, so the exercise assumptions hold. The main output-period theorem remains valid.

## Publication review, 12 November 2026

A valid binary shuffle has gap period eight where the added bound gives at most four.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

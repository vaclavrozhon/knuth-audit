# F158 — A martingale need not remain a martingale with constant information

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / Mathematical Preliminaries Redux, answer 77, p. 382

A local example in the proof is incorrect. Delete that example or use the martingale’s own history. The main implication proved in exercise 77 remains valid.

The parenthetical example in answer 77 is false. Let Z0=0 and Zn=ξ for n≥1, where ξ is a fair ±1 variable. This is a bounded martingale. If an auxiliary sequence is constant in time, Xn=Y, adaptedness forces ξ to be determined by Y, so E(Z1|Y)=ξ rather than Z0=0. The same witness excludes a deterministic constant helper.

## Publication review, 12 November 2026

Answer MPR77: a process Z0=0, Zn=xi for n>=1, with xi a fair sign, is a martingale in its own history but cannot be one relative to a time-constant auxiliary sequence. Adaptedness would reveal xi already at time 0, contradicting its conditional mean zero then.

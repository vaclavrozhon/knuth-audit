# F017 — The doomsday bound has the wrong initial value

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / p. 99–100, (76), doomsday function

Counting all nodes requires D(1) = 2.

D(1)=1 should be 2. Strict examples with 1, 2, and 5 options have 2, 3, and 7 nodes, exceeding the bounds 1, 2, and 6. Confirmed in the PDF and the author’s PostScript; no matching correction was found in the complete errata. The corrected recurrence, including constants, was proved for all n; the asymptotic exponent is unchanged. The physical copy has not been checked.

## Publication review, 12 November 2026

The doomsday recurrence needs D(1)=2 to count the root and solution leaf. This affects ordinary instances: the five distinct options a,b,c,ab,bc give seven search-tree nodes while the printed bound is six. The corrected initial sequence is 1,2,3,4,6,8,10,14,19,25,33,43. Its periodic constants become (200,263,350,464,608)/96; the exponential rate is unchanged.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

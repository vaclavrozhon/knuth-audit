# V4A-F0033 — The no-solution guard rejects the false function

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.1.4-9, printed page 622: initial test of s

Both constant cases are handled incorrectly: a valid all-ones solution is rejected, while the unsatisfiable case enters the traversal.

The answer seeks f(x)=0 but declares no solution when s=1, the representation of the identically false function. The guard should test s=2, the identically true function.

## Publication review, 12 November 2026

Answer 9, p. 622: the false function has s1=0 and s2=1, so the proposed s1 guard admits a function with no solutions. The guard must use s2. Page 207's terminal convention confirms the case.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

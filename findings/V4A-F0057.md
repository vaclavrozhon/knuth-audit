# V4A-F0057 — The matching bound loses the cycle orientation

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Exercise7.2.1.1-44, printed313: upper bound for d(n)

For n>=2 use 2*binomial(M(n),2); M(n)^2 is valid also for the one-bit case. The asymptotic estimate47 is unaffected.

The square has d(2)=2 oriented Gray cycles and M(2)=2 perfect matchings, so the claimed binomial(M(2),2)=1 bound fails. An unordered pair loses the cycle direction.

## Publication review, 12 November 2026

Exercise 7.2.1.1-44, p. 313: the square has two directed delta sequences starting at zero and only two perfect matchings, so the bound reads 2<=1. An unordered pair loses the cycle's direction. For n>=2 multiply the binomial bound by two.

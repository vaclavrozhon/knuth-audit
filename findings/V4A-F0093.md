# V4A-F0093 — The fixed-block generating function is missing k!

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.5–36, parenthetical explanation, printed 771

Replace the explanatory S(z)^k by S(z)^k/k!; the final exponential generating function is already correct.

The k-th power of the allowed-block series counts ordered blocks. Divide by k! to count set partitions with exactly k blocks.

## Publication review, 12 November 2026

Answer 7.2.1.5-36, p. 771: the generating function for exactly k unordered blocks is S(z)^k/k!, not S(z)^k. For two pairs on four elements the printed expression counts six instead of three. The outer exponential formula is correct.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V2-C0118 — The lcm consequence is missing an absolute value

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.5.2 · Exercise 15

The extended gcd algorithm is correct; a subsequent equality can have the wrong sign.

For u=1,v=2 the final coefficient vector is(−2,1,0), so v1·u=−2, whereas lcm(u,v)=2. Write |v1·u|=lcm(u,v). The preceding quotient formulas also require a separate(0,0) case. The general coefficient and sign argument is already recorded.

## Publication review, 12 November 2026

Algorithm X on u=1,v=2 ends with v_1=-2, so v_1*u is minus the least common multiple. Its absolute value is required. The separately allowed input (0,0) also needs an exception to the quotient expression.

# V2-C0103 — The auxiliary procedure returns a noncanonical zero

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.3.3

For e=1 and u=2^f−1, the auxiliary routine returns the modulus instead of canonical zero. The main reconstruction uses normalized inputs and remains correct.

Let e=1, f=2 and u=3. The inverse exponent is b=1, so there is no loop: initialization returns3, while (1*3) mod3=0. The input satisfies the stated u<2^f. Normalize u modulo2^f−1 at initialization or tighten the input range. This is a boundary defect in the separately stated helper and its initial invariant; it does not invalidate the main modular multiplication method.

## Publication review, 12 November 2026

The auxiliary input range permits e=1,f=2,u=3. Then b=1 and no iteration follows initialization, so the algorithm returns 3 rather than the canonical residue zero modulo 3. Normalize the initial residue or exclude this endpoint. The surrounding conversion already supplies canonical residues. The 2000 coprimality and 2025 conversion corrections are included and do not change this auxiliary bound.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

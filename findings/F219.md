# F219 — Binary propagation starts from the opposite literal

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer267, printed599/file619: Binary propagation starts from the opposite literal

Initialize l0←l; the G increment is in C3, not C4.

The C3 hook initializes l0 to not l even though l is the true trail literal.

## Publication review, 12 November 2026

SAT267 starts binary propagation from the complement of the true trail literal. With units a,not-b and binary clause not-a OR b stored only in BIMP, it checks two empty lists and falsely declares SAT. Start from the true literal and reference C3.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

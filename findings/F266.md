# F266 — The double-lookahead example counts eight literals instead of sixteen

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT main p.229: the double-lookahead example uses S=8 instead of S=16

A numerical error in the worked example. The definition of S, the displayed lookahead forest, and Algorithm Y are consistent with the corrected values.

The example should use S=16 and DT=258. It substitutes the number of free variables for the number of candidate literals.

## Publication review, 17 November 2026

Count the sixteen entries in equation (70). At its first entry T=2 and LO[0]=2. With Y=8, step Y2 computes BASE=0, LBASE=2*16*8=256 and DT=256+2=258.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# V3-C0007 — The proof appears to reuse P^S for a different operation

**Candidate · low severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / answer 5.1.4-13, p. 608

The notation is ambiguous; the deletion theorem itself is not disputed.

Page 56 defines P^S as the full dual tableau, while answer 5.1.4-13 appears to use it for one deletion. For permutation 213, one deletion yields row (2,3), but the full dual has first row (3,2). Writing d(P), as on page 57, would resolve the mismatch. This remains a candidate because the answer may intend a local overloading of the symbol. Relevant errata checked.

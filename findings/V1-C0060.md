# V1-C0060 — Huffman H needs a base case for a single weight

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · §2.3.4.5 · Exercise 13 answer · Printed page 596

A one-weight input writes outside the arrays; an explicit singleton return fixes the boundary case.

For the allowed input m = 1 and w1 = 1, the correct result is a single external root. H1 sets x = 1, i = 2, j = 0, k = 1. H2 chooses the sentinel at index 2; H3 then decrements k to 0 and writes L[0], R[0], A[0] outside the prescribed arrays. The later termination test misses this case. Return after copying the sole weight, before H2. The general algorithm for m ≥ 2, including negative weights, is correct. No corresponding repair was found in the four public errata layers checked on November 5, 2026. Later physical printings and priority have not been established.

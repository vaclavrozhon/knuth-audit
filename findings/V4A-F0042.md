# V4A-F0042 — The profile formula confuses a variable label with its position

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer7.1.4-158, printed page650: a_j and b_j subscripts

Use positions consistently in the profile formula; the subsequent asymptotic comparison is not refuted.

The conditions compare j*pi with the exceptional variable position k, but the profile coefficients are indexed by j instead of j*pi. The five-variable example has two exceptional-variable nodes where the printed rule gives one.

## Publication review, 12 November 2026

Answer 158, p. 650: the piecewise profile formula tests the position j*pi but indexes its sequences by the variable label j. In the five-variable example with order x1,x2,x5,x3,x4, two nodes test x5, whereas the printed b5 is one. Use the position consistently.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

# C022 — Six jigsaw search-tree sizes differ by one node

**Candidate · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answers 7.2.2.1–59 and 60, p. 428; search-tree sizes

The printed totals exclude one node compared with literal entries into Algorithm X’s X2 step.

Original DLX1 and an independent bitset model agree on every depth of all six search trees: 1106, 911, 123, 24, 27, 17. The book gives 1105, 910, 122, 23, 26, 16. The 911 result uses the stated GRANDTIME symbol order; alphabetical order changes the tree. Each puzzle has one solution, so excluding its successful leaf or the root explains the difference. Puzzle 60(c) provides the shortest illustration: 16 forced moves form a path with 17 nodes. The earlier 89-node example uses inclusive counting. This remains a candidate about counting conventions, not six confirmed errors. PDF and author PS agree; no matching erratum found.

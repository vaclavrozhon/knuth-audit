# V3-C0066 — The periodic-query bound omits the query length

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Exercise 6.3-40, printed 511, and answer 727: query time independent of pattern length

Use O(n) query time for the supplied Patricia construction, retaining O(N) storage.

An arbitrarily long matching query must be read; changing one unread bit can change the answer, so O(N) independent of n is impossible.

## Publication review, 12 November 2026

Exercise 6.3-40 permits arbitrary pattern length n independently of period N. For period 01 and pattern (01)^t, changing any one input bit destroys the match. Reading the pattern already takes order n time in the stated finite-word model. The O(N) query claim cannot hold uniformly in n.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

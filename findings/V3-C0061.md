# V3-C0061 — Tree reconstruction loses the parent during recursion

**Confirmed · medium severity.** 2nd edition · 1st printing · 1998.

Location: Answer 6.2.3-10, printed 715: TREE uses the changed global index after recursion

The printed reconstruction routine fails on a valid three-node AVL tree. Save the current node in a local pointer.

For inorder balance factors 0,0,0, the recursive call changes k from 2 to 3; the outer Q=X_k returns the right leaf instead of the root.

## Publication review, 12 November 2026

The recursive TREE routine on p. 715 uses global k after the right-subtree call has changed it. With inorder balance factors (0,0,0), that call advances k from 2 to 3; the outer Q=X_k then returns the right leaf instead of the root. Saving the current node in a local pointer repairs this. The 1995 first-edition replacement has the same shared-index defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

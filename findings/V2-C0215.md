The pretest is not safe with the preceding bound that guarantees
only one small proper divisor. Let
u=(x+1)(x^2+x+100)=x^3+2x^2+101x+100, B=20, and p^e=41>2B.
Order the irreducible modular factors as
v_1=x^2+x+18, v_2=x+1. The quadratic is irreducible modulo 41.

For r=2,d=1, F2 considers only v_1 (i_1=1). Its centered constant
18 does not divide 100, so the proposed pretest skips the combination
before testing its complement x+1, which is a genuine small factor.

With the weak bound, the combination must survive if either side's
constant passes. Alternatively, a separate modulus bound can ensure
correct reconstruction of every true constant. The original F with
a coefficient bound for all factors is unaffected.

## Publication review, 12 November 2026

The weaker factor bound on p. 452 does not justify the constant-coefficient filter before checking the complementary factor. For u=(x+1)(x²+x+100), B=20 and modulus 41, the only degree-two choice has constant coefficient 18, which fails the divisibility filter, while its complement x+1 is a valid small factor. The version bounding every factor remains valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

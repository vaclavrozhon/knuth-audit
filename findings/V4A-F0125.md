# V4A-F0125 — The extremal function in answer 82(c) is wrong for even n

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–82(c), printed 801

Use the threshold [nu(sigma)>=n/2], instead of (45), for this optimization problem. The main worst-case optimality result remains correct.

The strict-majority function (45) does not maximize the number of ones among functions requiring the maximum number of evaluations. For n=2, OR has three ones and AND has only one, while both require three evaluations.

## Publication review, 12 November 2026

Answer 7.2.1.6-82(c), p. 801: for n=2 both AND and OR require three evaluations in Algorithm H, but OR has three positive outputs rather than one. The maximizing threshold is weight >= ceil(n/2), not weight > n/2. The odd-n answer and main worst-case lower bound remain valid.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

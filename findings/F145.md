# F145 — Deleting a blocked option can falsely reject a solvable problem

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–221, p. 475

The printed loop visits the first node twice and can report that no solution exists.

Answer 221 starts at q=x and continues while q≥x. The end spacer points back to the first node, so the same row is processed again. With primary items a,b and secondary s, the rows a s:1 / a / b s:2 have the solution {2,3}. Deleting the correctly rejected first row follows addresses 5→6→7→5, then incorrectly enters P9. A standalone verifier uses an explicit memory table; the corrected loop preserves the solution. Both the book PDF and author draft contain the error. No matching correction was found in six archived errata layers. The native author program uses a different, correct termination rule.

## Publication review, 12 November 2026

Answer 221: the q>=x loop revisits its starting node after the end spacer points back to x. With primary a,b and secondary s, options a s:1, a, b s:2, deleting the first option falsely reaches P9 although the last two solve the instance. A post-test q>x traversal, or processing the first node last, removes each node once.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

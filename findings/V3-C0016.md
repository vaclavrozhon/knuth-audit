# V3-C0016 — The dictionary key does not reproduce the punctuation example

**Confirmed · low severity.** 2nd edition · 1st printing · 1998.

Location: Volume 3 / answer 5-4, p. 585

The proposed extension puts a- before A, contrary to the displayed dictionary order.

After case folding and punctuation removal, a, A and a- have the same primary key. Ordering the original strings as secondary keys must put a before A to match the example; then lexicographic order necessarily puts a- before A as well. Thus the displayed a < A < a- cannot follow from the stated two-key rule. The basic case-only method is correct; punctuation requires an additional tie-breaking rule or a different example. Original typesetting and all relevant archived errata checked; no matching correction found.

## Publication review, 12 November 2026

The pair-key rule on p. 585 is inconsistent with its displayed dictionary order: obtaining a before A from the secondary alphabet forces a- before A, while the example has A before a-. The issue is the internal rule/example mismatch, not a dispute over real dictionaries' conventions.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

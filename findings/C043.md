# C043 — Does “main options” include the unused-vertex options?

**Candidate · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–261(b), p.482

Reading the phrase as arc options alone would omit paths that skip an internal vertex.

Answer 261(a) calls arc options “main” and introduces unused-vertex options separately. Part (b) asks for the main options. The latter phrase might mean the full construction, so this remains a wording candidate. Retaining the unused-vertex options makes the construction work.

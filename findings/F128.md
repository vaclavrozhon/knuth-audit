# F128 — The two-way stair encoding uses the wrong diagonal

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.1–92; answer pp. 436–437

The published reduction rejects its own valid five-letter example.

Both printed down-word families use cells (i+j,j), so the second family demands reversed left-down words. For WAVES / LINED / LEPER it asks for DEPIW / REVEL / SENAL instead of the actual right-down words SEPAL / DEVIL / RENEW. Keep the reversed letter order but change the row offsets in the d_i options from i+j to i−j modulo p. The literal interpreter and original DLX2 both give zero models before this change and one afterwards with the across rows fixed. PDF and author PS agree; no matching erratum was found. A physical copy remains unchecked.

## Publication review, 12 November 2026

Answer 92: right-stair constraints require the i-j diagonal index, with the appropriate reversed color sequence, instead of i+j. The WAVES/LINED/LEPER example directly distinguishes the two diagonals; a two-letter certificate also distinguishes the resulting solution sets. The earlier marker-name erratum does not fix the index.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

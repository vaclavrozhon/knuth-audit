# F041 — A proof step violates the conditioning requirement

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT 356(a), p. 618

The overlapping cliques are not partitioned as the argument requires.

The decomposition of overlapping cliques does not satisfy the disjoint-conditioning requirement. Valid parameters and two disjoint events with p=2/5 yield the false intermediate bound 2/3≤2/5. Assigning each vertex to the last clique corrects the proof; the theorem is valid. Confirmed in the PDF and PostScript.

## Publication review, 12 November 2026

Answer 356(a): the conditioning set can overlap the clique, so the induction hypothesis does not apply. For the documented three-clique construction with disjoint events of probability 2/5, the asserted conditional bound is 2/3<=2/5. Assigning each vertex to its last containing clique repairs the partition and the final avoidance product.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

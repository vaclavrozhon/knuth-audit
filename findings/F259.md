# F259 — Minimality witness uses the wrong permutation direction

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / 7.2.2.2–230, p.592: permutation direction in the minimality witness

The explicit satisfying assignment is wrong. The minimal-unsatisfiability claim is repaired by reversing the permutation direction.

After deleting M_(j0,m), the listed permutation gives the wrong element the largest rank. For m=3 and j0=1, the proposed assignment still violates M_23.

## Publication review, 17 November 2026

Set m=3 and j0=1. The printed ranks (2,3,1) make row 2 entirely false, so M_23 is false although only M_13 was removed. Replace the ranks by (3,1,2), or set x_(p_i,p_j)=[i<j].

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

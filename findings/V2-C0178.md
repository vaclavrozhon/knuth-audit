# V2-C0178 — Rounding down does not establish the displayed bound

**Confirmed · low severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · §4.5.4 · printed 667

Using the ceiling repairs the proof. Failure of the floor-only enumeration itself has not been established.

The initialization uses floor(sqrt(N/s)), but the claimed bound on sqrt(lambda*mu*s) need not hold; N=36 provides the recorded witness.

## Publication review, 12 November 2026

The auxiliary assertion sqrt(lambda*mu*v)<=floor(sqrt(N/s)) fails for N=36,r=1,s=5 and lambda=mu=1: sqrt(5)>2. A ceiling makes the proof valid with the same asymptotic bound. Retain this inequality defect only; the stored small-input checks do not establish that keeping the floor causes a missing divisor.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

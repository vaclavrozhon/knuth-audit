# F212 — Literal deletion need not preserve satisfiability

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT answer217, printed590/file610: Literal deletion need not preserve satisfiability

Answer false, or add the complementary-pivot assumptions needed for ordinary resolution.

Answer217 incorrectly declares the statement true for nontautological clauses; A=B={l} is a counterexample.

## Publication review, 12 November 2026

SAT217's answer is false as posed: A=B={l} are simultaneously satisfiable, but deleting both signs of l leaves the empty clause. A={l,a}, B={l,b} also refutes the printed proof's claim about the particular covering assignment. Ordinary resolution with complementary pivot assumptions is unaffected.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

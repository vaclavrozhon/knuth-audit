# F040 — The minimum ranges over the wrong objects

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT 356(b), p. 349

It should range over cliques containing the vertex, rather than neighboring vertices.

The minimum should range over cliques j with i∈U_j, not adjacent vertices. Otherwise, a single edge and single clique require undefined θ12 and Σ2. This is separate from the known 2017 reference correction. Confirmed in the PDF and PostScript.

## Publication review, 12 November 2026

Exercise 356(b): minimize over clique indices j with i in U_j. The printed neighbor index confuses vertices with cliques and can refer to undefined theta and Sigma values even for one edge covered by one clique. The answer already uses the intended membership condition.

# F269 — Signed cycle repeats a negated literal

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.2–494(iii), p.365: signed cycle repeats a negated literal

A local notation error in the question. Removing one negation restores the intended symmetry and agrees with the printed answer.

Exercise494(iii) repeats NOT j in both cycles and omits j. The displayed object is not the required signed permutation.

## Publication review, 17 November 2026

Read the third cycle pair on p365. A signed permutation must map opposite literals to opposite literals. The printed overlapping cycles fix j but move NOT j. Change (i NOT j NOT k)(NOT i NOT j k) to (i NOT j NOT k)(NOT i j k).

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

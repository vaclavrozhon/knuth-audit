# F157 — Two kakuro memory figures use MB instead of KB

**Confirmed · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–263(g), p.484

The table overstates Algorithm C’s memory scale by a factor of one thousand.

The unmodified and modified kakuro rows print 509 MB and 537 MB. The intended unit is KB. Using the declared input sizes and the original DLX2 structures gives conservative upper bounds of 904708 and 950204 bytes, both below 1 MB. The exact rounded 509/537 KB values were not independently reproduced. Both sources print MB.

## Publication review, 12 November 2026

Answer 263(g): the two Algorithm C memory entries use MB where KB is intended. The actual node and item structures give conservative bounds 904708 and 950204 bytes, below 1 MB. The precise rounded 509 and 537 KB values were not independently reproduced.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

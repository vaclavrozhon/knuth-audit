# V2-C0141 — The weighted gcd bound loses a gcd factor

**Confirmed · medium severity.** 3rd edition · 1st printing · 1997.

Location: Volume 2 · Section 4.5.3 · Printed pages 379, 656

For u=4,v=2,lambda=9/4,mu=1, the claimed threshold is 3/2 but all candidate absolute values exceed it.

For u=4,v=2,lambda=9/4,mu=1, the claimed threshold is 3/2 but all candidate absolute values exceed it. The proof loses the factor d in the remainders. Using sqrt(lambda mu v), or normalizing the remainder coordinates by d, yields a generally proved correction.

## Publication review, 12 November 2026

The original square root contains v/d, while the continuant product for the unnormalized remainder includes d. With u=6,v=4 and both weights one, the three tested absolute values are 4,3-sqrt(2),2, all greater than sqrt(2). This example uses no split final quotient. Restoring d and using sqrt(lambda*mu*v), or normalizing all remainders by d, repairs the proof.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

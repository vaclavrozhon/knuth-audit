# V1-C0063 — Compaction translates NULL into a live pointer

**Confirmed · critical severity.** 3rd edition · 1st printing · 1997.

Location: Volume 1 · Exercise 34 · page 615, lines 50–52

A valid null pointer becomes a non-null pointer during compaction.

The program explicitly assumes LINK(0) is nonzero, but translates every link field through LINK without skipping NULL. Even one live two-word node with a null field can acquire a self-reference.

Insert J6Z before line 51, jumping to the loop test at line 53. The abstract algorithm already skips null fields.

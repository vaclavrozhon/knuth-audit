# V4A-F0027 — The component splice writes through the null pointer

**Confirmed · medium severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.1.3-179, step I4, printed page 612: joining the transferred child list

The splice can write through a null pointer and fail to preserve the active component tree.

I4 traverses the children of an absorbed component until R=Lambda, then assigns SIB(R)=Q. It must link the last actual child to Q.

## Publication review, 12 November 2026

Answer 179, p. 612, I4: after traversing a nonempty transferred child list, R is null when SIB(R) is assigned. Rows 1111111,1000001,1001001,0000000 reach the case. The 2012 erratum removes the saved last-node pointer but leaves this null write unchanged.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

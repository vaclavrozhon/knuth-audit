# V4A-C0002 — Possible uncorrected use of generalized consensus for compatible columns

**Candidate · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / §7.1.2, p.120, Decomposition of partial functions

The referenced consensus need not exist; the bipartite characterization itself remains valid using the intersection instead.

Compatible subcubes 0*={00,01} and *0={00,10} have no generalized consensus under exercise 7.1.1–32(a). Page 120 nevertheless invokes that object. The known correction to answer 32(a), p.540, removes a false sufficiency claim and leaves the definition unchanged. The full proof now isolates the remaining ambiguity: the answer’s coordinate operation does produce the nonempty intersection for compatible cubes, so page 120 may be using the name informally for that operation. The bipartite characterization remains valid. Kept as a candidate concerning this terminology, not as another card for the known correction. Original typesetting and all five relevant errata layers were checked.

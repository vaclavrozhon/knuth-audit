# F006 — The entropy formula uses the wrong argument

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / MPR 121(d), p. 24, definition of entropy

The expression needs the probability mass function evaluated at Y.

H_Y=E lg(1/Y) is missing the probability mass function y; it should read E lg(1/y(Y)). For Y=2 with certainty, the printed expression gives −1, whereas the entropy is 0. Confirmed in the PDF and the author’s PostScript.

## Publication review, 12 November 2026

MPR 121(d), p. 24: entropy requires E(log_2(1/y(Y))), not E(log_2(1/Y)). A variable identically equal to two has entropy zero but the printed expression is -1.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

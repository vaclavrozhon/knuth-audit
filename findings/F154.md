# F154 — The path-count product uses n instead of n−1

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–261(c), p.482

Both the general product and the displayed value of P16 have a one-step parameter shift.

Answer 261(c) uses a product through n for n−1 paths. The smallest case n=2 has two paths, while the printed product gives five. The corrected P16 is 10606175914819584; the printed 992340657705109416 is P17. Small exact path sets, native DLX6, an independent exact Pfaffian and Knuth’s original note support the correction. Book and draft agree.

## Publication review, 12 November 2026

Answer 261(c): n=2 has two paths, while the printed product gives five. Its upper index must be n-1. The quoted value for P16 is actually P17; the corrected P16 is 10606175914819584. The source note uses n paths in a square of side n+1, explaining the shift.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

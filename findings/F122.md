# F122 — The identity-element construction leaves isolated diagonal items

**Confirmed · high severity.** 1st edition · 2nd printing · 2022.

Location: 4B / p. 432, answer 7.2.2.1–76(c)

The printed exact-cover model rejects every order n≥2, including valid two-element examples.

Answer 76(c) removes items with x=0 or y=0 but retains all positive diagonal items xx. None of its remaining options contains these items. Identity 0 forces x∘x=0, so the diagonal must also be removed. The two-element XOR table 01/10 is already a counterexample: the printed model has item 11 and no options. Removing x=y gives the intended bijection with idempotent semisymmetric quasigroups on n−1 elements. General proofs and complete small solution sets were checked independently. Both PDF and author PS contain the omission; no matching erratum was found. A physical copy remains unchecked.

## Publication review, 12 November 2026

DLX 76(c): an identity element 0 forces x composed with x to equal 0. The reduced item universe must therefore omit diagonal items too. At order two, the legitimate XOR table exists, whereas the literal reduction leaves item 11 with no covering option.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

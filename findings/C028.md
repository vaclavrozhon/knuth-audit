# C028 — The torus count needs one more normalization step

**Candidate · low severity.** 1st edition · 2nd printing · 2022.

Location: 4B / answer 7.2.2.1–97, p. 437

The stated XCC input returns three color translates of each torus.

Pairing type 00 with position p00 leaves 17,388 XCC solutions: 5,796 for each upper-left color. Fixing d00=0 removes the remaining three translations and gives the printed 5,796. Independent complete cell enumeration and original DLX2 have identical model sets. The geometric count and 2,898 transpose pairs are correct. This is a candidate for making the normalization explicit, not a confirmed error in the number of tori.

# F206 — Lookahead reset uses a literal index in the variable array

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / SAT Algorithm X stepX2, printed228/file248: Variable-array reset

Use VAL[|l|]; with free x1 and fixed x2,x3, the printed encoded indices2,3 erase both real assignments.

Step X2 writes VAL[l] although VAL is indexed by the underlying variable |l|.

## Publication review, 12 November 2026

Step X2 indexes the variable array VAL by an encoded literal. In a reachable state for (x2),(x3),(x1 OR x2), the free literals 2 and 3 erase the true values of x2 and x3. Use the underlying variable index. The July 2020 erratum introduced this defective line; it is not an existing correction of the defect.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

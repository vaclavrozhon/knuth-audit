# V4A-F0113 — The unary example specifies the wrong number of leaves

**Confirmed · low severity.** 1st edition · 1st printing · 2011.

Location: 4A / Answer 7.2.1.6–37, unary example beginning “if t=1”, printed 791

The intended slow-case example has n_0=r+1 and n_1=m.

With n_0=m+r+1 and n_1=m the count is binomial(2m+r,m), not binomial(m+r,r).

## Publication review, 12 November 2026

Answer 7.2.1.6-37, p. 791: the unary-forest combination example needs n_0=r+1, not m+r+1. For m=2,r=1 the printed forest class contains ten objects rather than the intended three. The later fixed-r lower-bound discussion survives.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.

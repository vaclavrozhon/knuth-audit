# F126 — The update estimate skips the cost of a dead end

**Confirmed · medium severity.** 1st edition · 2nd printing · 2022.

Location: 4B / exercise 7.2.2.1–86, p. 133; answer p. 434

The estimate omits an update that the stated exhaustive algorithm performs at each zero-option branch.

For theta=0 the proposed trial skips C4. Ordinary Algorithm C still covers that empty item and assigns LLINK(r), counting one update. One primary item with no options therefore costs 1 update but is estimated as 0. The nonempty input p x; q x under primary p,q and secondary x costs 5 but is estimated as 4. Original DLX2 confirms both totals. Execute and account for C4 before returning from a zero-option node, without sampling. The empty uncover itself is idempotent and is not counted as another structural fault. PDF and author PS agree; no matching correction was found. The physical copy remains unchecked.

## Publication review, 12 November 2026

Answer 86: when the selected item is empty, the early jump skips the LLINK(r) update. The single empty primary item has full update count 1 but estimate 0; a nonempty two-option example has 5 versus 4. Account for C4 even when theta is zero.

Decision: `retained`. No matching prior report was found in the checked sources; absolute priority is not established.
